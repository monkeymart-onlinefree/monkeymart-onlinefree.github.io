Use the Number Sequence Calculator to find a requested term in an arithmetic, geometric, or Fibonacci sequence. Enter the sequence type and term position, plus the first term and difference or ratio when required, to see the calculated term, a sequence preview, and supported finite sum.

What Is the Number Sequence Calculator?

The Number Sequence Calculator works with three common sequence types: arithmetic, geometric, and Fibonacci.

For arithmetic and geometric sequences, it calculates the nth term, displays the beginning of the sequence, and finds the finite sum through the requested term. Fibonacci mode calculates the exact Fibonacci number at the selected zero-based position and displays a preview of the sequence.

How to Use the Number Sequence Calculator

Sequence Type

Choose one of three options:

  • Arithmetic: Each term changes by a constant difference.
  • Geometric: Each term is generated using a constant ratio.
  • Fibonacci: Each term after the first two is the sum of the previous two.

First Term (a₁)

For arithmetic or geometric mode, enter the first number in the sequence.

The calculator accepts finite numeric values, including integers, negative numbers, and decimals.

This input is not used in Fibonacci mode.

Difference d / Ratio r

For an arithmetic sequence, enter the common difference d.

For a geometric sequence, enter the common ratio r.

The calculator treats this as an ordinary numeric value. Fibonacci mode does not use this input.

Term Position n

Enter the position of the term you want to calculate.

  • Fibonacci: n can be 0 through 1000
  • Arithmetic: n must be at least 1
  • Geometric: n must be at least 1
  • n must always be a whole number
  • Maximum supported n is 1000

Fibonacci uses zero-based indexing, so F₀ = 0 and F₁ = 1.

Formula / Calculation Method

Arithmetic Sequence Formula

For an arithmetic sequence, the calculator uses:

aₙ = a₁ + (n − 1)d

Variables

  • aₙ = value of the nth term
  • a₁ = first term
  • d = common difference
  • n = term position

The calculator also calculates the finite arithmetic sum:

Sₙ = n(a₁ + aₙ) / 2

where Sₙ is the sum of the first n terms.

Geometric Sequence Formula

For a geometric sequence, the calculator uses:

aₙ = a₁r^(n − 1)

Variables

  • aₙ = value of the nth term
  • a₁ = first term
  • r = common ratio
  • n = term position

For r ≠ 1, the finite geometric sum is:

Sₙ = a₁(1 − rⁿ) / (1 − r)

If r = 1, every term equals the first term, so the calculator uses:

Sₙ = a₁ × n

The standard geometric-sequence and finite-series relationships are consistent with established mathematical references.

Fibonacci Sequence Method

Fibonacci mode begins with:

F₀ = 0
F₁ = 1

Each later term is calculated with:

Fₙ = Fₙ₋₁ + Fₙ₋₂

For example:

0, 1, 1, 2, 3, 5, 8, 13, 21, ...

This recurrence is the standard definition of the Fibonacci numbers.

The calculator generates Fibonacci values using exact integer arithmetic rather than ordinary floating-point numbers.

Calculation Sequence

  1. The calculator checks the selected sequence type.
  2. It verifies that n is a whole number from 0 to 1000.
  3. Arithmetic and geometric modes additionally require n ≥ 1 and valid finite values for the first term and difference or ratio.
  4. The appropriate nth-term calculation is performed.
  5. Arithmetic and geometric modes calculate the finite sum.
  6. A preview of up to the first 18 terms is generated.
  7. Results are formatted for readable display.

Sequence Preview

Arithmetic and geometric previews begin with the first term and continue using the selected difference or ratio.

When more than 18 terms are requested, the calculator displays the first 18 terms followed by an ellipsis.

Fibonacci previews begin at F₀ and are also limited to the first 18 displayed terms when the requested position is larger.

Result Formatting

For arithmetic and geometric calculations, ordinary results are displayed with floating-point noise removed and up to about 10 decimal places where needed.

Values with an absolute size of at least 10¹² are displayed in scientific notation.

If an arithmetic or geometric calculation grows beyond the finite numeric range supported by the browser, the calculator reports that the result is too large for standard numeric display.

Worked Example

Suppose you have a geometric sequence with:

Inputs

  • First term a₁ = 3
  • Common ratio r = 2
  • Term position n = 6

Step 1: Calculate the Sixth Term

Use:

aₙ = a₁r^(n − 1)

Substitute the values:

a₆ = 3 × 2^(6 − 1)
a₆ = 3 × 2⁵
a₆ = 3 × 32
a₆ = 96

Step 2: Calculate the Finite Sum

Because r ≠ 1:

Sₙ = a₁(1 − rⁿ) / (1 − r)

Substitute the values:

S₆ = 3(1 − 2⁶) / (1 − 2)
S₆ = 3(1 − 64) / −1
S₆ = 3(−63) / −1
S₆ = 189

Step 3: Sequence Preview

The first six terms are:

3, 6, 12, 24, 48, 96

Final Result

6th term = 96
Finite sum = 189

Understanding Your Results

nth Term

The main result is the value at the requested sequence position.

For arithmetic and geometric sequences, counting starts with a₁ as position 1.

For Fibonacci mode, counting is zero-based, starting with F₀ = 0.

Sequence Preview

The preview helps you check the pattern visually. It displays up to 18 terms, so a long sequence does not fill the page with hundreds of values.

Finite Sum

Arithmetic and geometric modes show the total of all terms from the first term through the requested nth term.

Fibonacci mode does not calculate or display a finite sum; the sum field is shown as unavailable.

Assumptions and Limitations

Arithmetic and geometric calculations use JavaScript's standard numeric representation. Very large values can therefore exceed the browser's finite-number range, especially when a geometric sequence grows rapidly.

Decimal arithmetic may also contain very small floating-point representation differences. The calculator formats ordinary results to remove common display noise rather than showing unnecessary decimal digits.

Fibonacci mode uses exact integer arithmetic, so Fibonacci terms through the supported n = 1000 limit are calculated without floating-point rounding. The sequence preview is limited to 18 displayed terms for readability.

Arithmetic and geometric sequences require a positive term position beginning at n = 1. Fibonacci is different because the calculator defines the sequence from F₀.

Frequently Asked Questions

What is an arithmetic sequence?

An arithmetic sequence has a constant difference between consecutive terms. This calculator uses aₙ = a₁ + (n − 1)d to calculate the requested term.

What is a geometric sequence?

A geometric sequence is generated using a constant ratio between successive terms. The nth term is calculated with aₙ = a₁r^(n − 1).

What happens when the geometric ratio is 1?

When r = 1, every term is equal to the first term. The calculator therefore calculates the finite sum as a₁ × n instead of dividing by 1 − r.

Why does Fibonacci start at n = 0?

This calculator uses zero-based Fibonacci indexing: F₀ = 0 and F₁ = 1. Therefore, entering n = 0 returns 0.

Can I enter n = 0 for an arithmetic or geometric sequence?

No. Arithmetic and geometric calculations require n ≥ 1 because the first entered value is defined as a₁. Fibonacci mode allows n = 0.

Why does the sequence preview stop after 18 terms?

The preview is intentionally limited to the first 18 terms to keep long sequences readable. The requested nth term is still calculated separately.

Why can a geometric result become too large?

Repeated multiplication can make geometric terms grow extremely quickly. If the calculated term or sum exceeds the finite range supported by JavaScript's standard numeric type, the calculator cannot display it as a normal finite number.
