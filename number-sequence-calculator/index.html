What Is a Number Sequence Calculator?

A number sequence calculator finds terms in arithmetic, geometric, or Fibonacci sequences. It can also display a preview of the sequence and, where appropriate, the finite sum through the requested term.

Arithmetic Sequence Formula

aₙ = a₁ + (n−1)d, where a₁ is the first term, d is the common difference, and n is the term position. The finite sum is Sₙ = n(a₁+aₙ)/2.

Geometric Sequence Formula

aₙ = a₁r^(n−1). For r ≠ 1, the finite sum is Sₙ = a₁(1−rⁿ)/(1−r).

Fibonacci Sequence

Fibonacci numbers begin 0, 1, 1, 2, 3, 5… Each term after the first two is the sum of the previous two. This page uses zero-based indexing, so F₀ = 0.

Limitations

Very large geometric terms can exceed JavaScript’s finite-number range. Fibonacci terms are calculated with exact integers but long outputs are truncated to keep the page readable.

Frequently Asked Questions

What is an arithmetic sequence?

An arithmetic sequence changes by a constant difference. Its nth term is aₙ = a₁ + (n−1)d.

What is a geometric sequence?

A geometric sequence changes by a constant ratio. Its nth term is aₙ = a₁r^(n−1).

How is the Fibonacci sequence defined here?

This page uses F₀=0, F₁=1, and Fₙ=Fₙ₋₁+Fₙ₋₂.

Can the calculator show large Fibonacci terms?

Yes. The Fibonacci mode uses JavaScript BigInt for exact integer terms up to the input limit shown by the form.
