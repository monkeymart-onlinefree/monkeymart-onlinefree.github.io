The Average Return Calculator helps measure investment performance using a series of returns or dated account values and cash flows. Enter return percentages or starting and ending balances, dates, and an optional deposit or withdrawal to calculate the applicable average, cumulative, or money-weighted return.

What Is the Average Return Calculator?

An Average Return Calculator measures how an investment performed over multiple periods or across dated cash flows.

It can be useful when comparing a sequence of investment returns, measuring compounded growth, finding the total cumulative return, or estimating an annualized return when money was deposited or withdrawn during the investment period.

Arithmetic and geometric averages answer different questions. Arithmetic mean measures the simple average of individual returns, while geometric mean reflects compounding across periods.

Formula / Calculation Method

Arithmetic Average Return

The arithmetic mean adds the individual period returns and divides the total by the number of returns:

Arithmetic Average = (r₁ + r₂ + ... + rₙ) / n

Where:

Variable Meaning Unit
r₁, r₂ ... rₙ Individual period returns converted from percentages to decimals Decimal return
n Number of return periods Periods

The arithmetic average does not compound one period's gain or loss into the next period.

Geometric Average Return

The geometric mean compounds the growth factor for every return and then takes the nth root:

Geometric Average = [(1 + r₁)(1 + r₂)...(1 + rₙ)]^(1/n) − 1

The result represents the constant compounded return that would produce the same ending growth over the same number of equal periods.

Geometric averaging is particularly useful for compound growth across time-series observations. When returns vary, the geometric mean is generally below the arithmetic mean.

Cumulative Return

For a series of returns, cumulative return measures the combined gain or loss after compounding the periods:

Cumulative Return = [(1 + r₁)(1 + r₂)...(1 + rₙ)] − 1

Unlike an average return, cumulative return describes the total compounded change across the complete sequence rather than a typical return for one period.

Money-Weighted Annualized Return

When starting and ending balances, dates, and an intermediate deposit or withdrawal are used, the calculator solves for an annual rate that makes the discounted dated cash flows balance to zero:

Σ [CFᵢ / (1 + R)^tᵢ] = 0

Where:

Variable Meaning Unit
CFᵢ Signed cash flow included in the calculation Currency
R Money-weighted annualized return being solved for Decimal annual rate
tᵢ Elapsed time associated with each dated cash flow Years as determined from dates

This type of calculation considers both the amount and timing of cash entering or leaving an investment. Irregular-dated internal-rate-of-return methods similarly solve for a rate that makes the discounted cash-flow value equal to zero.

Calculation Sequence

  1. Percentage returns are converted to decimal form.
  2. For arithmetic return, the returns are added and divided by the number of periods.
  3. For geometric return, each return is converted to a growth factor, the factors are multiplied, and the nth root is applied.
  4. Cumulative return uses the compounded growth factors without converting the total into an average per period.
  5. For dated cash-flow calculations, the starting balance, ending balance, dates, and optional deposit or withdrawal are used to numerically solve for the money-weighted annualized rate.

Worked Example

Assume an investment has three annual returns:

Inputs

Year 1: 10%
Year 2: -5%
Year 3: 8%

Step 1: Arithmetic Average

(10% − 5% + 8%) / 3
= 13% / 3
= 4.33%

Step 2: Cumulative Return

Convert the returns to growth factors:

1.10 × 0.95 × 1.08 = 1.1286

Therefore:

Cumulative Return = 1.1286 − 1 = 0.1286
Cumulative Return = 12.86%

Step 3: Geometric Average

Geometric Average = (1.1286)^(1/3) − 1
≈ 0.041150

Final Result

For these three annual returns:

Arithmetic Average Return: 4.33%

Geometric Average Return: approximately 4.12% per year

Cumulative Return: 12.86%

The arithmetic average is higher because it does not account for the compounding effect of the negative and positive returns.

Understanding Your Results

Arithmetic average return is the simple mean of the entered returns. It can help summarize a set of observations but does not show the exact compounded growth of an investment.

Geometric average return represents the constant compound return that would create the same overall growth over equal periods. For annual return observations, it can be interpreted as the compound average annual return.

Cumulative return shows the total percentage gain or loss produced by the entire sequence of compounded returns.

Money-weighted annualized return considers when money was added to or removed from the account. Because cash-flow timing affects this result, it can differ from an average based only on period returns. Calculator.net similarly separates return calculations based on account cash flows from calculations based on multiple investment returns.

Assumptions and Limitations

This calculator does not adjust investment returns for inflation, taxes, investment fees, benchmark performance, risk, or volatility unless those effects are already reflected in the values you enter.

The dated cash-flow calculation supports the starting balance, ending balance, dates, and the optional intermediate cash flow provided by the calculator. It should not be treated as a model for a more complex sequence of irregular cash flows beyond the functionality available in the tool.

Arithmetic and geometric returns can produce noticeably different results when returns fluctuate. The arithmetic mean does not reproduce compounded account growth.

Calculated historical returns describe past performance. They are not forecasts or guarantees of future investment results. The SEC also notes that fees, methodology, economic conditions, and other assumptions can materially affect how investment performance should be interpreted.

Frequently Asked Questions

What is the difference between arithmetic and geometric average return?

Arithmetic return is the simple average of the individual returns. Geometric return compounds the returns and calculates the constant per-period rate that would produce the same overall growth.

Why is the geometric return often lower than the arithmetic return?

When returns fluctuate, losses and gains compound on different account values. This creates a compounding effect that the arithmetic average does not capture. CFA Institute materials note that the geometric mean is below the arithmetic mean when observations have variation.

What does cumulative return mean?

Cumulative return is the investment's combined percentage gain or loss across all entered periods after compounding. It is a total-period result rather than an average for one period.

What is a money-weighted return?

A money-weighted return measures performance while accounting for the size and timing of cash flows. Deposits and withdrawals can therefore change the calculated return even when the beginning and ending balances remain the same.

Do deposits increase the investment return?

Not automatically. A deposit increases the account balance, but the money-weighted calculation separates the effect of added capital from investment performance by considering when that deposit occurred.

Does the calculator include fees, taxes, or inflation?

No separate adjustment for fees, taxes, or inflation is included in this calculator. If those costs have already affected the return or balance values you enter, their effects may already be reflected indirectly in the result.

Can average return predict future investment performance?

No. An average return summarizes the values entered into the calculator. Historical investment performance does not predict future returns, and actual future gains or losses can differ substantially.
