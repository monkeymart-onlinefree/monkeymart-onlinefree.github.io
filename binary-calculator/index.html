What Is a Binary Calculator?

A binary calculator performs arithmetic on base-2 integers. Binary uses only the digits 0 and 1. This calculator keeps integer operations exact with JavaScript BigInt and also shows the same result in decimal and hexadecimal notation.

How to Use the Binary Calculator

  1. Enter two binary integers using only 0 and 1, with an optional leading minus sign.
  2. Choose add, subtract, multiply, or divide.
  3. Run the calculation to see base-2, base-10, and base-16 outputs.

How Binary Place Value Works

bₙ…b₂b₁b₀ = Σ bᵢ × 2ⁱ

Binary is base 2. Hexadecimal is base 16, and because 16 = 2⁴, each hexadecimal digit corresponds to exactly four binary bits.

Calculation Example

1010₂ equals 10₁₀ and 11₂ equals 3₁₀. Their sum is 13₁₀, which is 1101₂ or D₁₆.

Limitations

This calculator is for integers, not binary fractions or IEEE-754 floating-point encodings. Division returns an integer quotient and remainder, matching BigInt integer division.

Frequently Asked Questions

Why is hexadecimal useful with binary?

One hex digit maps exactly to four bits, so long binary values can be written much more compactly without changing the underlying integer value.

Does this calculator support negative binary numbers?

Yes, a leading minus sign is supported as a mathematical signed integer. It does not interpret fixed-width two's-complement bit patterns.
