The Stair Calculator calculates the number and height of risers, number of treads, total stair run, stringer length, and stair angle for a straight stair layout. Enter the total rise, maximum riser height, tread depth, stair width, and measurement unit to estimate the main stair dimensions.

What Is the Stair Calculator?

The Stair Calculator helps plan the basic geometry of a straight staircase. It divides the total vertical rise into equal risers, determines the required number of treads, calculates horizontal run, and uses right-triangle geometry to estimate the stringer length and overall pitch angle.

It is useful for preliminary stair planning, layout comparisons, and checking basic residential stair dimensions before detailed construction or code review.

How to Use the Stair Calculator

Total Rise: Enter the total vertical distance from the lower finished floor level to the upper finished floor level.

Maximum Riser: Enter the greatest riser height you want the calculation to allow. The calculator uses this value to determine how many risers are required.

Tread Depth: Enter the horizontal depth used for each tread. This value determines the total horizontal run.

Stair Width: Enter the width of the stair. This is used for the calculator's width-related result or reference check.

Measurement Unit: Select the unit used for the stair measurements and keep dimensional inputs consistent.

All dimensional values used in the stair geometry should be positive. A zero or negative rise, riser limit, or tread depth cannot produce a meaningful stair layout.

The calculator first determines how many risers are required, then calculates the actual riser height, tread count, total run, stringer length, and stair angle.

The ceiling function ⌈ ⌉\lceil \ \rceil rounds the required riser count upward to the next whole number when necessary. This ensures that dividing the total rise by the resulting number of risers does not exceed the entered maximum riser value.

Calculation Sequence

  1. Divide total rise by maximum riser height.
  2. Round the result upward to obtain a whole number of risers.
  3. Divide total rise by the riser count to find the actual riser height.
  4. Subtract one from the number of risers to determine the number of treads.
  5. Multiply tread count by tread depth to calculate total run.
  6. Apply the Pythagorean theorem to total rise and total run to calculate stringer length.
  7. Use inverse tangent of total rise divided by total run to calculate the overall stair angle.

IRC Geometry and Width Reference

For reference, the 2021 International Residential Code lists a maximum conventional stair riser height of 7¾ inches (196 mm) and a minimum tread depth of 10 inches (254 mm). It also specifies a minimum clear stairway width of 36 inches (914 mm) above the permitted handrail height, with separate clear-width provisions where handrails occupy the stair width.

A calculator geometry or width indication should therefore be treated as a basic comparison, not as confirmation that a staircase complies with every applicable requirement.

The right-triangle stringer and inverse-tangent angle calculations follow standard Pythagorean and trigonometric relationships.

Understanding Your Results

Actual Riser is the equal vertical height assigned to each calculated riser. It may be lower than the maximum riser value because the calculator rounds the required number of risers upward.

Total Run is the horizontal distance represented by the calculated tread count multiplied by the entered tread depth.

Stringer is the straight-line diagonal length formed by the total rise and total run. It is a geometric length estimate and does not account for material cuts, bearing details, overhangs, or structural connection requirements.

Angle is the overall incline calculated from total rise and total run.

IRC Geometry provides a basic reference for stair dimensions where the calculator presents such a check. It does not evaluate every code provision.

Width reflects the entered stair width or its basic reference status. Actual code-required clear width can depend on handrails and other construction details.

Assumptions and Limitations

This calculator models a straight stair flight using total rise, equal risers, equal tread depths, and a constant horizontal run.

It does not design or verify landings, guards, handrails, winders, nosings, headroom geometry, framing connections, live loads, or stringer cut strength.

The stringer result is a geometric diagonal measurement rather than a structural design calculation. Actual material length may need to account for cuts, bearing surfaces, installation details, and construction tolerances.

The calculator also does not determine whether the stair structure can safely carry required loads.

Displayed results may be rounded, so construction layout should be based on verified field measurements and sufficient working precision rather than repeatedly rounding intermediate values.

Building codes may be amended by states, cities, or other jurisdictions. Always verify the code edition and local amendments that apply to the project before construction.

Current Rules / Data

As of September 2026, ICC publishes the 2024 International Residential Code (IRC) as its current model residential-code edition.

The IRC is a model code, and jurisdictions can adopt different editions or make local amendments. ICC provides adoption information for checking jurisdiction-specific code use.

The calculator's basic geometry should therefore be used for planning and estimation rather than as a substitute for approval by a building department, engineer, architect, or other qualified professional when required.

Frequently Asked Questions

How does the Stair Calculator determine the number of risers?

It divides the total rise by the entered maximum riser height and rounds the result upward to the next whole number. The total rise is then divided equally among those risers.

Why is the actual riser lower than the maximum riser I entered?

The maximum riser is a limit used to determine the minimum number of whole risers required. Once that number is known, the full rise is divided evenly, so the actual riser can be slightly smaller.

Why is the number of treads one less than the number of risers?

The implemented straight-stair method calculates tread count as:

T=N−1T=N-1

For example, 14 risers produce 13 calculated treads.

How is stringer length calculated?

The calculator treats total rise and total run as the perpendicular sides of a right triangle. Stringer length is the hypotenuse:

S=H2+L2S=\sqrt{H^2+L^2}

This is a geometric estimate, not a structural stringer design.

How is the stair angle calculated?

The calculator uses inverse tangent:

θ=tan⁡−1(H/L)\theta=\tan^{-1}(H/L)

where HH is total rise and LL is total run.

Does an IRC result mean my stairs meet building code?

No. Basic riser, tread, and width comparisons cover only part of stair-code requirements. Local rules may also regulate headroom, landings, handrails, guards, nosings, loads, openings, and other details.

Can I use the calculated stringer length to cut a stringer directly?

Use it as a geometric reference only. Actual stringer layout and material length can depend on tread and riser cuts, top and bottom connections, bearing details, material dimensions, and structural requirements.
