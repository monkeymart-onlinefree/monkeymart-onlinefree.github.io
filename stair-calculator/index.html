What Is a Stair Calculator?

A stair calculator converts floor-to-floor rise into a practical number of equal risers and treads. For a straight flight it can also estimate total horizontal run, pitch angle, and diagonal stringer length. These are geometric planning values, not a complete structural or permit design.

Stair Calculation Formulas

Risers = ceil(Total Rise ÷ Maximum Riser)
Actual Riser = Total Rise ÷ Risers
Treads = Risers − 1
Total Run = Treads × Tread Depth
Stringer = √(Rise² + Run²)
Angle = atan(Rise ÷ Run)

Calculation Example

With a 108-inch total rise, a 7.5-inch target maximum riser, and a 10-inch tread, the calculator first rounds the required riser count upward, then redistributes the rise equally so every riser is the same height.

Residential Code Reference

The 2021 International Residential Code lists a 7¾-inch maximum riser height, 10-inch minimum tread depth, 36-inch minimum clear stair width, and 6 ft 8 in minimum headroom for the general residential stair provisions cited here. Adopted local rules and exceptions can differ.

Limitations

This tool does not design landings, guards, handrails, winders, nosings, headroom geometry, framing connections, live loads, or stringer cut strength. Verify the locally adopted code and structural requirements before construction.

Sources and Methodology

Frequently Asked Questions

How many risers do I need?

The calculator divides total rise into equal risers while keeping each riser at or below your chosen maximum. The number of treads is normally one less than the number of risers when the upper floor acts as the final walking surface.

What is a comfortable stair angle?

There is no single universal comfort angle. This calculator reports the geometric angle and separately checks common residential riser and tread limits; local building rules control actual construction.

Does the calculator replace a building code review?

No. Stair requirements vary by jurisdiction and occupancy. Use the code check as a planning aid and verify the adopted local code, permits, landings, guards, handrails, and structural details.

What does stringer length mean?

The reported stringer length is the straight diagonal length from the bottom to the top of the calculated run and rise, before allowing for cuts, bearing, attachment details, or material waste.
