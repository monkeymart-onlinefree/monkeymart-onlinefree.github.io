What Is a Permutation and Combination Calculator?

This calculator counts selections from n distinct objects taken r at a time. A permutation counts different orders as different outcomes, while a combination treats different orders of the same selected objects as one outcome.

How to Use the Calculator

Enter the total number of distinct objects n and the number selected r. The calculator returns nPr and nCr for selection without replacement. Both n and r must be nonnegative integers and r cannot exceed n.

Permutation and Combination Formulas

Without replacement, P(n,r) = n!/(n−r)! and C(n,r) = n!/[r!(n−r)!]. The factorial n! multiplies all positive integers from n down to 1, with 0! = 1.

Calculation Example

For n = 6 and r = 2, there are 6 × 5 = 30 permutations because order matters. Dividing by 2! removes the duplicate orderings, giving 15 combinations.

When Does Order Matter?

Use permutations for ordered roles, rankings, codes without repeated symbols, or arranged positions. Use combinations when you only care which items are selected, such as choosing a committee from a larger group.

Limitations

This calculator uses distinct objects and selection without replacement. Cases with repeated objects or selection with replacement use different formulas.

Frequently Asked Questions

What is the difference between nPr and nCr?

nPr counts ordered arrangements, while nCr counts unordered selections. For the same n and r, nPr is nCr multiplied by r!.

What is 0 factorial?

By definition, 0! = 1. This convention keeps many counting formulas consistent, including cases where r = 0 or r = n.

Can r be greater than n?

Not for the no-replacement calculations on this page. You cannot select more distinct objects than the set contains.

Does this calculator allow repetition?

No. It calculates standard permutations and combinations without replacement. Repetition requires different formulas.
