What Is a GPA Calculator?

Answer: A GPA calculator computes a credit-weighted average of grade points. Each course grade point is multiplied by its credit value, and total quality points are divided by total credits.

How to Use the GPA Calculator

  1. Add each course, credit value, and letter grade.
  2. Add or remove course rows as needed.
  3. Optionally enter a prior GPA and prior credits.
  4. Calculate semester and cumulative GPA.

GPA Formula

GPA = Σ(grade points × course credits) ÷ Σ(course credits)

Calculation Example

A 3-credit A course contributes 12 quality points. A 4-credit B+ course contributes 13.2 quality points on this default scale.

Assumptions and Limitations

Institutions use different grade scales and policies. This default 4.0 mapping should be changed if your school assigns different point values or weighting.

GPA Calculator FAQs

Does GPA weight courses by credits?

Yes. More-credit courses contribute proportionally more quality points.

Can I include my prior cumulative GPA?

Yes. Enter both prior GPA and completed credits to combine them with the current courses.

Do all schools use the same 4.0 scale?

No. Grade-point mappings and weighting rules vary by institution.
