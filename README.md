# CalcPro Batch 4

Batch 4 adds 10 dedicated calculators across math, geometry, health, finance, and everyday tools.

## Added calculators
- Fraction Simplifier
- Rectangle Perimeter
- Pythagorean Theorem
- Body Surface Area
- Calorie Deficit
- Markup Calculator
- Sales Tax Calculator
- Fuel Cost Calculator
- Unit Price Calculator
- Tip Calculator

## Validation
Run:

```bash
node --check app.js
node test.js
```

This is a static GitHub Pages project. Health and financial outputs are estimates and should be checked against appropriate professional guidance when decisions are important.
