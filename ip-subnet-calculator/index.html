What Is an IP Subnet Calculator?

An IP subnet calculator separates the network prefix from the host portion of an address. For IPv4, it can show the dotted-decimal subnet mask, network address, broadcast address, and address count. For IPv6, the prefix length identifies how many of the 128 address bits belong to the subnet prefix.

IPv4 CIDR Math

An IPv4 address has 32 bits. A /24 prefix leaves 8 host bits, so the block contains 2^8 = 256 addresses. Traditional subnets with prefixes /30 or shorter reserve the all-zero host value as the network address and the all-one host value as broadcast.

Special IPv4 Prefixes

A /31 is commonly used for point-to-point links under modern standards, while /32 identifies a single host route. These do not follow the simple “subtract two usable hosts” rule.

IPv6 Prefixes

IPv6 addresses are 128 bits. A /64 prefix leaves 64 bits after the subnet prefix, representing 2^64 possible interface identifiers within that prefix space.

Frequently Asked Questions

How many addresses are in a /24 IPv4 subnet?

A /24 leaves 8 host bits, so the block contains 256 total IPv4 addresses.

What is the subnet mask for /24?

The dotted-decimal mask is 255.255.255.0.

How many bits are in an IPv6 address?

IPv6 addresses are 128 bits long.
