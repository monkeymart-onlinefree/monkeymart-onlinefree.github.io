Use the Roman Numeral Converter to convert an Arabic number such as 1994 into a Roman numeral such as MCMXCIV, or convert a Roman numeral back into its numeric value. Enter either a whole number or a Roman numeral to get the corresponding result.

What Is the Roman Numeral Converter?

The Roman Numeral Converter translates values between Arabic numbers and Roman numeral notation. It is useful for dates, chapter numbers, outlines, titles, historical references, clocks, monuments, and other situations where Roman numerals are used.

Standard Roman numerals use the symbols I, V, X, L, C, D, and M, representing 1, 5, 10, 50, 100, 500, and 1,000. Standard subtractive combinations such as IV, IX, XL, XC, CD, and CM are used where appropriate.

How to Use the Roman Numeral Converter

Enter an Arabic number or Roman numeral in the calculator.

If you enter an Arabic number, the calculator converts it into canonical Roman numeral notation.

If you enter Roman numeral text, the calculator calculates its numeric value and checks whether the entered numeral matches the canonical form for that number.

For numeric dates, the same conversion rules can be applied to individual whole-number date components. For example, 2026 can be written as MMXXVI.

Formula / Calculation Method

Main Conversion Method

The calculator converts Arabic numbers by repeatedly selecting the largest Roman numeral value that does not exceed the remaining number.

The standard descending conversion values are:

Value Roman Numeral
1000M
900CM
500D
400CD
100C
90XC
50L
40XL
10X
9IX
5V

1I

These values reflect standard additive and subtractive Roman numeral notation.

For an Arabic number NN:

  1. Find the largest Roman value VV that is less than or equal to NN.
  2. Add its Roman symbol to the result.
  3. Calculate:
    N = N − V
  4. Repeat until the remaining value is zero.

Variables

  • N = the number or remaining numeric value being converted
  • V = the Roman numeral value selected during the current step
  • R = the final Roman numeral string
  • C(N) = the canonical Roman numeral produced from numeric value N

Roman numerals are symbolic numbers, so there is no physical measurement unit involved.

Roman Numeral Validation

For Roman numeral input, the calculator uses a round-trip validation method:

  1. Convert the entered Roman numeral into its numeric value.
  2. Convert that numeric value back into canonical Roman notation.
  3. Compare the generated canonical notation with the entered notation.
  4. Treat the input as canonical only when the forms match.

Conceptually:

Valid Roman input if entered Roman numeral = C(N)

This prevents non-canonical combinations from being treated as the preferred standard representation.

For example, IIII can be interpreted arithmetically as 4, but the standard modern form is IV. The Government of Canada notes that IIII can still appear by tradition on some clock faces, illustrating why historical or stylistic notation can differ from canonical conversion rules.

Worked Example

Convert 1994 to Roman numerals.

Inputs

Arabic number: 1994

Step 1

The largest Roman value not greater than 1994 is:

M = 1000

1994 − 1000 = 994

Result so far: M

Step 2

The largest available value not greater than 994 is:

CM = 900

994 − 900 = 94

Result so far: MCM

Step 3

The largest available value not greater than 94 is:

XC = 90

94 − 90 = 4

Result so far: MCMXC

Step 4

The remaining value is 4:

IV = 4

4 − 4 = 0

Final Result

1994 = MCMXCIV

The same numeral converts back to 1994 because:

M + CM + XC + IV = 1000 + 900 + 90 + 4 = 1994

Understanding Your Results

When you enter an Arabic number, the main result is its canonical Roman numeral representation.

For example:

The value is represented as 40 + 9 rather than IL because standard subtractive notation uses specific combinations such as XL and IX.

Arabic Number Result

When you enter a valid Roman numeral, the result is its equivalent numeric value.

For example:

MMXXVI → 2026

Input Validation

Roman numeral input is checked against its canonical converted form. An arrangement that calculates to a number but does not match the converter's canonical output may therefore be rejected as non-standard.

Assumptions and Limitations

The calculator is designed for whole-number Roman numeral conversion rather than decimal or fractional calculations.

No rounding is required because Roman numeral conversion works with discrete integer values.

The converter follows canonical modern Roman notation. Historical inscriptions and specialized styles can use alternative forms. For example, IIII may appear instead of IV on some clock faces.

Some systems also use an overline or vinculum to represent values multiplied by 1,000. These extended forms are different from ordinary Latin-letter Roman notation and should not be assumed unless the calculator interface explicitly supports them.

Unicode also contains dedicated Roman numeral characters, but the Unicode Standard recommends using sequences of ordinary Latin letters for most purposes.

Use the calculator's displayed validation for any input restrictions or limits enforced by the tool.

Frequently Asked Questions

What are the seven basic Roman numerals?

The seven basic symbols are I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, and M = 1000.

Why is 4 written as IV instead of IIII?

Canonical notation uses IV, meaning one before five, or 5 − 1. IIII is a historical variant still seen on some clock faces but is not the usual canonical representation.

Why is 99 written as XCIX instead of IC?

Standard subtractive notation permits specific pairs. Ninety is XC and nine is IX, so 99 is written XCIX, not IC.

How does the calculator detect an invalid Roman numeral?

It converts the entered Roman text into a numeric value and then converts that value back into canonical Roman notation. If the regenerated numeral does not match the entered canonical form, the input fails the canonical-format check.

Does Roman numeral conversion require rounding?

No. The conversion works with whole-number symbol values, so there is no decimal rounding step.

Can I use Roman numerals for dates?

Yes. Roman numerals are sometimes used for years and other date-related numbering. You can convert individual numeric date components using the same whole-number conversion rules.

Can Roman numerals be written with special Unicode characters?

Unicode provides dedicated Roman numeral characters, but for most purposes the Unicode Standard recommends composing Roman numerals with ordinary Latin letters such as I, V, X, L, C, D, and M.
