Use the Matrix Calculator to add, subtract, or multiply two matrices. Enter Matrix A and Matrix B using commas between values and semicolons between rows, then choose A + B, A − B, or A × B to calculate the resulting matrix.

What Is the Matrix Calculator?

The Matrix Calculator is a mathematical tool for performing three common matrix operations: addition, subtraction, and multiplication.

It is useful for students, teachers, engineers, and anyone working with numerical matrices who wants to check matrix calculations quickly without working through every entry manually.

Matrix addition and subtraction require matrices with the same dimensions. Matrix multiplication is possible when the number of columns in Matrix A equals the number of rows in Matrix B.

How to Use the Matrix Calculator

Matrix A

Enter the first matrix. Separate values in the same row with commas and separate rows with semicolons.

Example:

1,2;3,4

This represents:

A=[1234]A= \begin{bmatrix} 1 & 2\\\ 3 & 4 \end{bmatrix}

Matrix B

Enter the second matrix using the same format.

Example:

5,6;7,8

This represents:

B=[5678]B= \begin{bmatrix} 5 & 6\\\ 7 & 8 \end{bmatrix}

Operation

Choose one of the available operations:

  • A + B — add the matrices
  • A − B — subtract Matrix B from Matrix A
  • A × B — multiply Matrix A by Matrix B

The dimensions of the matrices must be compatible with the selected operation.

Formula / Calculation Method

Matrix Addition

Two matrices can be added only when they have the same number of rows and columns.

Each entry in the result is calculated by adding the corresponding entries:

(A+B)ij=aij+bij(A+B)\_{ij}=a\_{ij}+b\_{ij}

For example:

[1234]+[5678]=[681012]\begin{bmatrix} 1 & 2\\\ 3 & 4 \end{bmatrix} + \begin{bmatrix} 5 & 6\\\ 7 & 8 \end{bmatrix} = \begin{bmatrix} 6 & 8\\\ 10 & 12 \end{bmatrix}

Matrix addition by corresponding entries and the equal-dimension requirement are standard matrix-operation rules.

Matrix Subtraction

Matrix subtraction also requires Matrix A and Matrix B to have identical dimensions.

Each corresponding entry in Matrix B is subtracted from Matrix A:

(A−B)ij=aij−bij(A-B)\_{ij}=a\_{ij}-b\_{ij}

For the same matrices:

[1234]−[5678]=[−4−4−4−4]\begin{bmatrix} 1 & 2\\\ 3 & 4 \end{bmatrix} - \begin{bmatrix} 5 & 6\\\ 7 & 8 \end{bmatrix} = \begin{bmatrix} -4 & -4\\\ -4 & -4 \end{bmatrix}

Matrix Multiplication

If Matrix A has mm rows and nn columns, and Matrix B has nn rows and pp columns, the product ABAB has dimensions m×pm\times p.

The number of columns in A must therefore equal the number of rows in B.

The calculator uses:

(AB)ij=∑kaikbkj(AB)\_{ij}=\sum_k a\_{ik}b\_{kj}

Each result entry is found by multiplying the corresponding values from a row of A and a column of B, then adding those products.

Variables

  • AA = first input matrix
  • BB = second input matrix
  • aika\_{ik} = entry in row ii, column kk of Matrix A
  • bkjb\_{kj} = entry in row kk, column jj of Matrix B
  • (AB)ij(AB)\_{ij} = entry in row ii, column jj of the product matrix
  • ii = row position in the result
  • jj = column position in the result
  • kk = position used to pair entries from the row of A with the column of B

Matrix entries themselves do not require a physical unit. If your matrix values represent measurements such as distance, cost, or quantity, interpret the result according to the meaning of those original values.

Calculation Sequence

For A + B:

  1. Confirm that A and B have the same dimensions.
  2. Match entries with the same row and column positions.
  3. Add each pair of corresponding entries.
  4. Place each calculated value in the same position in the result matrix.

For A − B:

  1. Confirm that A and B have the same dimensions.
  2. Match corresponding entries.
  3. Subtract each entry of B from the matching entry of A.
  4. Build the result matrix from those differences.

For A × B:

  1. Check that the number of columns in A equals the number of rows in B.
  2. Take one row from Matrix A.
  3. Take one column from Matrix B.
  4. Multiply the corresponding entries.
  5. Add those products.
  6. Store the sum in the corresponding position of the result matrix.
  7. Repeat for every row-column combination.

Understanding Your Results

The main result is a new matrix produced by the selected operation.

For addition and subtraction, the result has the same dimensions as the two input matrices.

For multiplication, if A is an m×nm\times n matrix and B is an n×pn\times p matrix, the result is an m×pm\times p matrix.

Each value in the output corresponds to a specific row and column position. For multiplication, an output entry represents the dot product of a row from A and a column from B.

Assumptions and Limitations

This calculator performs numerical matrix calculations. It is not designed for symbolic matrix proofs or symbolic algebra.

Addition and subtraction are defined only when Matrix A and Matrix B have equal dimensions.

Multiplication is defined only when the number of columns in Matrix A equals the number of rows in Matrix B.

Matrix multiplication is order-dependent. In general, ABAB and BABA are not the same, and one product may be defined even when the other is not.

Calculations involving decimal values can sometimes show tiny differences caused by computer floating-point representation. These small numerical effects are different from the mathematical matrix rules themselves.

Frequently Asked Questions

Can matrices of different sizes be added?

No. Matrix addition requires both matrices to have the same number of rows and the same number of columns because entries are added position by position.

Can matrices of different sizes be multiplied?

Yes, if their dimensions are compatible. The number of columns in Matrix A must equal the number of rows in Matrix B.

For example, a 2×32\times3 matrix can be multiplied by a 3×43\times4 matrix, producing a 2×42\times4 result.

Is A × B the same as B × A?

Not generally. Matrix multiplication is not commutative, so ABAB and BABA can produce different results. In some cases, one multiplication may not even be defined.

How should I enter a matrix?

Use commas to separate values within each row and semicolons to separate rows.

For example:

1,2,3;4,5,6

represents a matrix with two rows and three columns.

What does each value in a matrix product represent?

Each value in the product is calculated from one row of the first matrix and one column of the second matrix. Their corresponding entries are multiplied and the products are added together.

Why can't I multiply some matrices?

Matrix multiplication requires compatible inner dimensions. If Matrix A has m×nm\times n dimensions, Matrix B must have nn rows for ABAB to be defined.

Does this calculator find determinants or matrix inverses?

No. This calculator is limited to the implemented operations A + B, A − B, and A × B.
