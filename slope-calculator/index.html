Use the Slope Calculator to find the slope of a line from two coordinate points: (x₁, y₁) and (x₂, y₂). The calculator uses the change in y divided by the change in x and also provides supporting values such as rise, run, line information, distance, angle, and direction.

What Is the Slope Calculator?

The Slope Calculator calculates the slope of the straight line passing through two points on a coordinate plane. Slope measures how much the y-value changes for each unit of change in the x-value.

This calculator is useful for coordinate geometry, algebra, graphing, rate-of-change problems, and checking calculations involving straight lines.

How to Use the Slope Calculator

Enter the coordinates of two points:

  1. x₁ – Enter the x-coordinate of the first point.
  2. y₁ – Enter the y-coordinate of the first point.
  3. x₂ – Enter the x-coordinate of the second point.
  4. y₂ – Enter the y-coordinate of the second point.

Coordinates do not have a fixed unit. If they represent measured quantities, use consistent units for both points.

The calculator then determines the slope and supporting information for the line defined by the two points.

Formula / Calculation Method

Main Slope Formula

The calculator uses:

m = (y₂ − y₁) / (x₂ − x₁)

The difference between the y-values is the rise, while the difference between the x-values is the run. This is the standard two-point slope formula.

Variables

  • m = slope of the line
  • x₁ = x-coordinate of the first point
  • y₁ = y-coordinate of the first point
  • x₂ = x-coordinate of the second point
  • y₂ = y-coordinate of the second point
  • Δy = y₂ − y₁ = rise
  • Δx = x₂ − x₁ = run

When units are attached to the coordinates, slope is expressed as y-units per x-unit.

Calculation Sequence

  1. Calculate the rise:
    Rise = y₂ − y₁
  2. Calculate the run:
    Run = x₂ − x₁
  3. Divide the rise by the run:
    Slope = Rise / Run
  4. If the run is zero, the two points form a vertical line and the slope is undefined.

Rise

The rise is the vertical change between the two points:

Rise = y₂ − y₁

A positive rise means the second point is higher than the first when read in the selected point order. A negative rise means it is lower.

Run

The run is the horizontal change:

Run = x₂ − x₁

The run is also the denominator of the slope formula. If the run equals zero, division cannot produce a finite slope.

Line Equation

After a finite slope is known, a line through one of the points can be represented using the point-slope equation:

y − y₁ = m(x − x₁)

This equation uses the calculated slope and one known point on the line.

Distance Between the Points

The straight-line distance between the two coordinates can be calculated as:

d = √[(x₂ − x₁)² + (y₂ − y₁)²]

This measures the direct distance from the first point to the second point on the coordinate plane.

Direction

The slope helps describe the line's direction as x increases. A positive slope rises from left to right, a negative slope falls, a zero slope is horizontal, and a vertical line has undefined slope.

The calculator also displays an angle as supporting line information. The exact angle normalization is not expanded here because the available calculator specification does not document that secondary calculation in enough detail to state its implementation formula without adding assumptions.

Worked Example

Suppose the two points are:

Inputs

  • x₁ = 2
  • y₁ = 3
  • x₂ = 6
  • y₂ = 11

Step 1: Calculate the Rise

Rise = 11 − 3 = 8

Step 2: Calculate the Run

Run = 6 − 2 = 4

Step 3: Calculate the Slope

m = 8 / 4
m = 2

Supporting Calculations

Using the point-slope equation:

y − 3 = 2(x − 2)

This simplifies to:

y = 2x − 1

The distance between the points is:

d = √[(6 − 2)² + (11 − 3)²]
d = √(16 + 64)
d = √80 ≈ 8.944

Final Result

The slope is 2.

This means y increases by 2 units for every 1-unit increase in x. Because the slope is positive, the line rises from left to right.

Understanding Your Results

Slope is the main result. It measures the rate of vertical change compared with horizontal change.

Rise shows the change in y between the two points.

Run shows the change in x between the two points.

Line equation represents the straight line passing through the supplied coordinates.

Distance represents the straight-line distance between the two points.

Angle gives additional information about the line's inclination.

Direction describes whether the line rises, falls, remains horizontal, or is vertical as x increases.

A larger absolute slope means a steeper nonvertical line. For example, a slope of 5 is steeper than a slope of 1, while −5 and 5 have the same slope magnitude but opposite directions.

Assumptions and Limitations

The calculator treats the entered values as two points in a standard Cartesian coordinate plane.

If x₁ = x₂ and the y-values are different, the line is vertical and its slope is undefined because the run equals zero.

If both entered points are identical, they do not define one unique line. Infinitely many different lines can pass through a single point.

Decimal and irrational supporting results may be rounded for display, so the displayed value can differ slightly from the full mathematical value.

The calculator determines the line from the entered coordinates only. It does not determine whether measured real-world data follows an exact linear relationship.

Frequently Asked Questions

What is the formula for slope between two points?

The formula is:

m = (y₂ − y₁) / (x₂ − x₁)

Subtract the first y-value from the second to get the rise, then divide it by the corresponding change in x.

What do rise and run mean?

Rise is the change in the y-coordinate, while run is the change in the x-coordinate. Slope is rise divided by run.

What does a positive slope mean?

A positive slope means the line rises from left to right as x increases.

What does a negative slope mean?

A negative slope means the line falls from left to right as x increases.

What does a slope of zero mean?

A zero slope occurs when the two points have the same y-coordinate but different x-coordinates. The resulting line is horizontal.

Why is the slope of a vertical line undefined?

A vertical line has x₂ − x₁ = 0. The slope formula would therefore require division by zero, so no finite slope is defined.

Does switching the two points change the slope?

No. Reversing the point order changes the signs of both the rise and run, so their ratio remains the same as long as the points define a nonvertical line.
