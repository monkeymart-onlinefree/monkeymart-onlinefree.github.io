The Speed Calculator calculates speed, distance, or time from the other known values. It also helps express speed in meters per second (m/s), kilometers per hour (km/h), miles per hour (mph), knots, or feet per second (ft/s).

What Is the Speed Calculator?

The Speed Calculator is a tool for solving the relationship between speed, distance, and elapsed time. You can use it for travel, running, cycling, engineering, science, or other situations where two values are known and the third needs to be calculated.

For a complete trip or measured interval, the calculated speed represents average speed—total distance divided by elapsed time.

How to Use the Speed Calculator

  1. Enter the two values you already know: Speed, Distance, or Time.
  2. Use the remaining quantity as the value to be calculated.
  3. Select the required Result unit when working with speed.
  4. Calculate the result and review the supporting values.

Speed

Enter speed when you already know how fast an object is moving and want to calculate distance or time.

Supported speed units include:

  • meters per second (m/s)
  • kilometers per hour (km/h)
  • miles per hour (mph)
  • knots
  • feet per second (ft/s)

Distance

Enter the distance traveled when calculating speed or elapsed time. Distance represents the length of the path traveled.

Time

Enter the elapsed time when calculating speed or distance. Time must not be zero when it is used as the divisor in a speed calculation.

Result Unit

Choose the unit in which a speed value should be expressed. The available speed units are m/s, km/h, mph, knots, and ft/s.

Formula / Calculation Method

Main Formula

The relationship between speed, distance, and time is:

Speed = Distance ÷ Time
v=dtv=\frac{d}{t}

The same relationship can be rearranged to calculate distance or time:

Distance = Speed × Time
d=v×td=v\times t
Time = Distance ÷ Speed
t=dvt=\frac{d}{v}

Average speed is defined as total distance traveled divided by elapsed time.

Variables

Suppose a vehicle travels 120 km in 2 hours. Find its average speed.

Step 2: Substitute the Values

Step 3: Calculate the Result

These are equivalent representations of the same speed using standard unit conversion factors.

Understanding Your Results

Speed

The speed result shows how much distance is covered per unit of time. For example, 60 km/h means an average of 60 kilometers would be covered in one hour if that rate were maintained.

Distance

When distance is calculated, the result represents:

Speed×Time\text{Speed}\times\text{Time}

For example, traveling at 50 km/h for 3 hours gives:

50×3=150 km50\times3=150\text{ km}

Time

When time is calculated, the result represents:

DistanceSpeed\frac{\text{Distance}}{\text{Speed}}

For example:

150 km50 km/h=3 hours\frac{150\text{ km}}{50\text{ km/h}}=3\text{ hours}

Converted Speed

A converted speed does not represent a different motion. It expresses the same rate using another unit, such as converting km/h to mph or m/s.

Assumptions and Limitations

The calculator uses the mathematical relationship between distance, time, and speed. Several limitations should be considered when interpreting a result.

  • A speed calculated from total distance and total elapsed time is an average speed. Actual speed may increase or decrease during the interval.
  • Speed is a scalar quantity and does not include direction. Velocity includes direction, so speed and velocity are not identical concepts.
  • Distance, time, and speed units must be consistent before applying the formula.
  • A divisor cannot be zero. Time must be greater than zero when calculating speed, and speed must be greater than zero when calculating time.
  • Measurement errors in distance or elapsed time will affect the calculated result.
  • Converted values can differ slightly depending on displayed decimal precision and rounding.
  • Real-world travel can include stops, acceleration, deceleration, route changes, and other conditions that are not represented by a simple average-speed calculation.

Frequently Asked Questions

What formula does the Speed Calculator use?

The main formula is:

Speed=DistanceTime\text{Speed}=\frac{\text{Distance}}{\text{Time}}

It can be rearranged to calculate distance as speed × time or time as distance ÷ speed.

Can I calculate distance from speed and time?

Yes. Use:

Distance=Speed×Time\text{Distance}=\text{Speed}\times\text{Time}

For example, 70 km/h for 2 hours equals 140 km.

Can I calculate travel time from speed and distance?

Yes. Use:

Time=DistanceSpeed\text{Time}=\frac{\text{Distance}}{\text{Speed}}

The speed and distance units must be compatible.

Which speed units are supported?

The calculator supports m/s, km/h, mph, knots, and ft/s.

Is speed the same as velocity?

No. Speed describes how fast something moves without specifying direction. Velocity includes both magnitude and direction.

Why can calculated speed differ from a speedometer or GPS reading?

A distance-and-time calculation normally produces average speed across an interval. A speedometer or GPS device may show speed at a particular moment, so the values can differ when speed changes during the trip.

Can time or speed be zero?

Zero speed can represent an object that is not moving, but it cannot be used as the divisor when calculating travel time. Likewise, zero elapsed time cannot be used to calculate speed because division by zero is undefined.
