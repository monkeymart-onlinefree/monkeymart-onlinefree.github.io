What Is the URL Encode / Decode?

The URL Encode / Decode tool converts text to or from URI percent-encoding. RFC 3986 represents an encoded octet as “%” followed by two hexadecimal digits. Encoding is context-sensitive because a character may be data in one component and a structural delimiter in another.

How to Use the URL Encode / Decode

Choose Encode or Decode. For encoding, select “URI component” for query values, path segments, and similar data, or “Whole URI” when the input is an already structured URL whose syntax delimiters should be preserved.

URL Encode / Decode Formula

Percent-encoded octet = “%” + two hexadecimal digits. For Unicode text, URI encoding uses the bytes of its UTF-8 representation.

Formula Variables

Reserved characters include URI delimiters such as :, /, ?, #, [, ], and @. Unreserved characters include letters, digits, hyphen, period, underscore, and tilde.

Calculation Example

A space in a normal URI component is encoded as %20. The text “green tea” therefore becomes “green%20tea” with URI-component encoding.

Understanding Your Results

The output is the encoded or decoded string. Decode errors are shown when the input contains malformed percent sequences.

Important Factors

Encoding a complete URL as if it were a component will also encode structural delimiters such as : and /. Conversely, preserving delimiters when you meant to encode a query value can change URL interpretation.

Limitations

This utility follows browser encodeURI/encodeURIComponent and corresponding decode functions. Application/x-www-form-urlencoded form data has additional conventions, including “+” for spaces, and is not identical to generic RFC 3986 percent-encoding.

Frequently Asked Questions

What is URL encoding?

URL encoding, more precisely percent-encoding, represents certain bytes as a percent sign followed by two hexadecimal digits, such as %20 for a space byte.

What is the difference between encodeURI and encodeURIComponent?

encodeURI is intended for a complete URI and preserves URI syntax delimiters. encodeURIComponent is for a component and encodes characters that could otherwise act as delimiters.

Should I encode a URL more than once?

Generally no. RFC 3986 warns that percent-encoding or decoding the same string more than once can change how percent signs and delimiters are interpreted.
