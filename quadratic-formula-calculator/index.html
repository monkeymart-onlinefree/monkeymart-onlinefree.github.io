The Quadratic Formula Calculator solves equations in the form ax² + bx + c = 0. Enter the coefficients a, b, and c to calculate the roots and supporting values such as the discriminant, vertex, and axis of symmetry.

What Is the Quadratic Formula Calculator?

A Quadratic Formula Calculator finds the solutions, or roots, of a quadratic equation using the quadratic formula. It is useful when a quadratic equation cannot be solved easily by factoring or when you want to check your algebra.

The calculator also helps describe the related parabola by showing the discriminant, vertex, and axis of symmetry. A valid quadratic equation requires a ≠ 0.

How to Use the Quadratic Formula Calculator

  1. Enter a, the coefficient of x². It must not be zero.
  2. Enter b, the coefficient of x.
  3. Enter c, the constant term.
  4. Calculate the result to find the roots and supporting quadratic values.

Positive, negative, zero, and decimal coefficients can be used where accepted by the calculator.

Formula / Calculation Method

For a quadratic equation written as:

ax² + bx + c = 0

the roots are calculated with the quadratic formula:

x = (−b ± √(b² − 4ac)) / (2a)

The expression inside the square root is called the discriminant:

D = b² − 4ac

For real coefficients, the discriminant indicates the type of roots. When D > 0, there are two distinct real roots. When D = 0, there is one repeated real root. When D < 0, the equation has two complex-conjugate roots.

Calculation Sequence

The calculator first evaluates the discriminant D = b² − 4ac. It then substitutes the coefficients and discriminant into the quadratic formula to calculate the two possible root values.

For the related quadratic function f(x) = ax² + bx + c, the axis of symmetry is:

x = −b / (2a)

The vertex lies on this axis. If:

h = −b / (2a)

then the vertex is:

(h, f(h))

OpenStax confirms that the axis of symmetry of a quadratic function is x = −b/(2a) and that the vertex's y-coordinate can be found by evaluating the function at this x-value.

First calculate:

Then evaluate:

k = ah² + bh + c

The vertex is:

(h, k)

Worked Example

Suppose the equation is:

x² − 5x + 6 = 0

Here:

a = 1, b = −5, c = 6

Step 1: Calculate the Discriminant

D = b² − 4ac
D = (−5)² − 4(1)(6)
D = 25 − 24 = 1

Because the discriminant is positive, the equation has two distinct real roots.

Step 2: Apply the Quadratic Formula

x = (−b ± √D) / (2a)
x = (5 ± √1) / 2

So:

x₁ = (5 + 1) / 2 = 3
x₂ = (5 − 1) / 2 = 2

Step 3: Find the Axis of Symmetry

x = −b / (2a)
x = −(−5) / (2 × 1)
x = 2.5

Step 4: Find the Vertex

Evaluate the quadratic at x = 2.5:

f(2.5) = (2.5)² − 5(2.5) + 6
f(2.5) = 6.25 − 12.5 + 6
f(2.5) = −0.25

Understanding Your Results

Roots are the values of x that make ax² + bx + c = 0 true. For a quadratic function, real roots correspond to the x-values where its graph reaches the x-axis.

The discriminant provides information about the number and type of roots before the complete root calculation is interpreted.

The axis of symmetry is the vertical line that divides the parabola into two mirror-image halves. The vertex is the point where this axis meets the parabola and represents the minimum point when the parabola opens upward or the maximum point when it opens downward.

Assumptions and Limitations

The quadratic formula applies only when a is not zero. If a = 0, the equation is no longer quadratic and should be solved as a lower-degree equation.

The root classification based on whether the discriminant is positive, zero, or negative assumes real coefficients. Irrational and complex results may be displayed as rounded decimal approximations because the calculator uses floating-point arithmetic.

Rounding can cause the displayed value to differ slightly from an exact symbolic result, especially when roots contain irrational numbers or coefficients have many decimal places.

Frequently Asked Questions

What happens if a = 0?

The equation is not quadratic when a = 0 because the x² term disappears. The quadratic formula divides by 2a, so a zero value for a is not valid for this calculation.

What does the discriminant tell me?

The discriminant is b² − 4ac. A positive value indicates two distinct real roots, zero indicates a repeated real root, and a negative value indicates two complex roots.

Can the calculator solve equations with complex roots?

Yes. A negative discriminant indicates a complex-conjugate pair of roots. These arise because the quadratic formula requires the square root of a negative value.

Why are some answers shown as decimals?

Roots involving irrational numbers cannot always be represented exactly as terminating decimals. The calculator therefore displays numerical approximations, and the final displayed value may be rounded.

What is the difference between a root and an x-intercept?

A root is an x-value that makes the quadratic expression equal to zero. When that root is real, it corresponds to an x-intercept of the graph of the related quadratic function.

How is the axis of symmetry calculated?

For f(x) = ax² + bx + c, the axis of symmetry is:

x = −b / (2a)

The vertex lies on this vertical line.

Can a quadratic equation have only one root?

It can have one distinct real root when the discriminant equals zero. In this case, both results from the quadratic formula have the same value, which is called a repeated or double root.
