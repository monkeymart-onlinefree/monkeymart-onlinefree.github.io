What Is a Percent Calculator?

Answer: A percent calculator solves relationships in which a value is expressed as a fraction of 100. It can also measure percentage change from an initial value and percentage difference between two values.

How to Use the Percent Calculator

  1. Choose the percentage problem type.
  2. Enter the two known values.
  3. Calculate the result.
  4. Check whether the chosen formula uses an initial value or the average of two values as its denominator.

Percentage Formulas

X% of Y = (X/100) × Y X is what % of Y = (X/Y) × 100 % change = (new − old) / old × 100 % difference = |A − B| / ((|A| + |B|)/2) × 100

Calculation Example

25% of 200 is 50. If a value rises from 80 to 100, the percentage change is (100−80)/80 × 100 = 25%.

Assumptions and Limitations

Percentage change is undefined when the initial value is zero. Percentage difference is symmetric, while percentage change is directional because it uses the initial value as the reference.

Percent Calculator FAQs

What does percent mean?

Percent means per hundred; 35% is equivalent to 0.35 or 35/100.

What is the difference between percentage change and percentage difference?

Percentage change compares a new value with an initial value. Percentage difference compares two values relative to their average without treating either one as the starting value.

How do I find 20% of a number?

Multiply the number by 0.20.
