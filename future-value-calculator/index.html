What Is a Future Value Calculator?

A future value calculator estimates what money may be worth at a later date after compound growth. This page combines a starting amount with optional recurring deposits, an interest rate per compounding period, and the number of periods.

Future Value Formula

For a lump sum, compound future value is:

FV = PV × (1 + r)^n

For equal deposits made at the end of each period, the annuity contribution is PMT × ((1+r)^n − 1) / r. If deposits are made at the beginning of each period, that annuity portion is multiplied by (1+r).

Formula variables

FV is future value, PV is the starting amount, r is the rate per period as a decimal, n is the number of periods, and PMT is the recurring deposit.

How to Use This Calculator

Enter a starting amount, number of periods, rate per period, and any recurring deposit. Choose whether deposits occur at the beginning or end of each period, then calculate. Make sure the rate and period use the same time unit.

Calculation Example

If $10,000 grows for 10 periods at 6% per period with $1,000 added at each period end, the calculator compounds the existing balance first and then applies each end-of-period deposit according to the ordinary-annuity convention.

Understanding the Result

The result separates money you supplied from growth generated by the assumed rate. The schedule makes timing visible, which is especially useful when comparing beginning-of-period and end-of-period deposits.

Limitations

Future value is a mathematical projection, not a guarantee. Real investments may have changing returns, fees, taxes, inflation, contribution changes, and losses that this simplified model does not automatically include.

Frequently Asked Questions

What is future value?

Future value is the amount an asset or cash flow is expected to be worth after it grows for a specified number of compounding periods at a given rate.

What is the difference between an ordinary annuity and an annuity due?

An ordinary annuity makes each deposit at the end of the period. An annuity due makes each deposit at the beginning, so each payment generally earns one additional period of growth.

What happens when the interest rate is zero?

When the rate is zero, future value is simply the starting amount plus all periodic deposits because there is no compounding growth.
