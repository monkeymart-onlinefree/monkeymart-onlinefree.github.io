What Is a Period Calculator?

A period calculator projects upcoming menstrual start and end dates using the first day of the last period, the usual cycle length, and the typical number of bleeding days.

How to Use the Period Calculator

Enter the first day of your most recent period, how many days bleeding usually lasts, and your average cycle length. The calculator projects the next six periods and an approximate ovulation date for the next cycle.

Period Prediction Formula

next period start = last period start + average cycle length. Each later projection repeats the same interval. The estimated ovulation cycle day is approximately cycle length minus 14; because the LMP is cycle day 1, the calendar-date offset is one day less.

Understanding the Calendar

The projected dates are planning estimates. Cycle length is counted from the first day of one period to the first day of the next, so bleeding duration is not added to the cycle length.

Limitations

Irregular cycles make date prediction less reliable. Seek medical advice for new or concerning changes, unusually heavy bleeding, severe pain, or persistent cycle changes.

Frequently Asked Questions

How are future period dates predicted?

Each next start date is calculated by adding your average cycle length to the previous predicted start date.

What counts as cycle day 1?

Cycle day 1 is the first day of menstrual bleeding.

How accurate is a period calculator?

It is most useful when cycles are regular. Illness, stress, hormonal changes, postpartum status, and other factors can shift the next period.

When is a cycle considered outside the typical adult range?

ACOG commonly describes adult menstrual cycles as typically about 21–35 days, although individual patterns and life stage matter.
