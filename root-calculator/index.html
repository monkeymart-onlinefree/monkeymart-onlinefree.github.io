The Root Calculator calculates square roots, cube roots, and general nth roots. Enter a number and the root index nn to find the corresponding real root when one exists.

What Is the Root Calculator?

A Root Calculator finds a value that produces the original number when raised to a specified power. It can be used for square roots, cube roots, and higher-order roots in mathematics, science, engineering, and everyday calculations.

For example, the square root of 25 is 5 because 52=255^2=25, while the cube root of 27 is 3 because 33=273^3=27.

How to Use the Root Calculator

Enter the following values:

Number: Enter the value whose root you want to calculate.

Root index nn: Enter the root order. An index of 2 represents a square root, 3 represents a cube root, and higher positive integer values represent higher-order roots.

The calculator then returns the calculated root when the requested root has a real-number result.

Formula / Calculation Method

Main Formula

The calculator uses the nth-root relationship:

xn=x1/n\sqrt[n]{x}=x^{1/n}

An nth root can also be defined as a value rr that satisfies:

rn=xr^n=x

Taking an nth root therefore reverses raising a value to the nth power.

Variables

  • xx = the number or radicand
  • nn = root index
  • xn\sqrt[n]{x} = calculated nth root

These values are dimensionless unless the number entered represents a quantity with its own units.

Calculation Sequence

  1. Read the entered number xx.
  2. Read the root index nn.
  3. Calculate the reciprocal exponent 1/n1/n.
  4. Evaluate x1/nx^{1/n}.
  5. Return the calculated root when a real-number result is defined.

Square Root

For n=2n=2:

x=x1/2\sqrt{x}=x^{1/2}

Example:

49=7\sqrt{49}=7

because:

72=497^2=49

Cube Root

For n=3n=3:

x3=x1/3\sqrt[3]{x}=x^{1/3}

Example:

1253=5\sqrt[3]{125}=5

because:

53=1255^3=125

Worked Example

Suppose you want to calculate the fourth root of 81.

Inputs

  • Number x=81x=81
  • Root index n=4n=4

Step 1

Apply the nth-root formula:

814=811/4\sqrt[4]{81}=81^{1/4}

Step 2

Find the value that gives 81 when raised to the fourth power:

34=813^4=81

Step 3

Therefore:

811/4=381^{1/4}=3

Final Result

3\boxed{3}

The fourth root of 81 is 3.

Understanding Your Results

The main result is the nth root of the number you entered.

For example:

  • A root index of 2 gives the square root.
  • A root index of 3 gives the cube root.
  • A root index of 4 gives the fourth root.
  • A root index of 5 gives the fifth root.

You can verify a result by raising the calculated root to the original root index. If the result is rr, then rnr^n should equal the original number xx, subject to normal numerical rounding.

Assumptions and Limitations

This calculator is intended for numerical root calculations rather than symbolic mathematical proofs.

For real-number calculations, an even root of a negative number is not a real number. Odd roots of negative real numbers are mathematically real; for example, the cube root of −8-8 is −2-2.

The standard nth-root definition uses a positive integer root index. An index of zero cannot be used in the formula x1/nx^{1/n} because 1/01/0 is undefined.

Some root results are irrational and cannot be represented as a finite decimal. Numerical calculations may therefore display a rounded approximation.

Browser-based numerical calculations commonly use finite-precision floating-point numbers, so very small representation differences can occur for some inputs and results.

Frequently Asked Questions

What is an nth root?

The nth root of xx is a value rr such that:

rn=xr^n=x

It can also be written as xn\sqrt[n]{x}.

What root index should I use for a square root?

Use a root index of 2. For example:

642=8\sqrt[2]{64}=8
What root index should I use for a cube root?

Use a root index of 3. For example:

643=4\sqrt[3]{64}=4
Can I calculate roots of negative numbers?

Odd roots of negative numbers can have real results. For example:

−273=−3\sqrt[3]{-27}=-3

Even roots of negative numbers do not have real-number results.

Why does a root result sometimes contain many decimal places?

Many roots are irrational numbers. For example, 2\sqrt{2} cannot be written as a terminating decimal, so numerical calculators must represent it with limited precision.

How can I check whether the calculated root is correct?

Raise the result to the root index. If r=xnr=\sqrt[n]{x}, then:

rn=xr^n=x

Small decimal differences may appear when the calculation involves floating-point rounding.

Is an nth root the same as raising a number to a fractional power?

For the real-number cases covered by the formula, the calculator uses:

xn=x1/n\sqrt[n]{x}=x^{1/n}

So taking an nth root corresponds to using the reciprocal 1/n1/n as the exponent.
