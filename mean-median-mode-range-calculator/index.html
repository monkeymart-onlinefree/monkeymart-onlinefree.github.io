What Is a Mean Median Mode Range Calculator?

This calculator finds four common descriptive statistics from a list of numbers. The mean is the arithmetic average, the median is the middle ordered value, the mode is the most frequent value or values, and the range is the difference between the largest and smallest values.

How to Use It

Enter values separated by commas, spaces, semicolons, or line breaks and select Calculate. The result tiles show mean, median, mode, range, minimum, maximum, count, and sum.

Mean, Median, Mode, and Range Formulas

Mean = Σx/n. To find the median, sort the data; use the middle value for an odd count or average the two middle values for an even count. Mode is the value with the greatest frequency. Range = maximum − minimum.

Calculation Example

For 10, 2, 38, 23, 38, 23, 21, the sum is 155 and n = 7, so the mean is about 22.1429. The ordered list has 23 in the middle. Both 23 and 38 occur twice, so the data is bimodal. The range is 38 − 2 = 36.

Which Measure Should You Use?

Mean uses every value but is sensitive to extreme values. Median is often more resistant to outliers. Mode is useful when frequency matters and can also be used with categories. Range is easy to interpret but depends only on the minimum and maximum.

Limitations

These measures summarize a data set but do not describe its full distribution. Two data sets can have the same mean or median and still have very different shapes or variability.

Frequently Asked Questions

What happens if there are two modes?

Both values are modes when they tie for the highest frequency. The calculator lists all tied modes.

How is the median calculated with an even number of values?

After sorting the data, the median is the arithmetic mean of the two middle values.

Can there be no mode?

Yes. If no value occurs more frequently than the others, the data set has no repeated mode.

Does the range use every value?

No. Range uses only the maximum and minimum values, so it can be strongly affected by a single extreme observation.
