What Is a Password Generator?

A password generator creates a random string from an allowed character set. This version performs the selection in the browser with the Web Crypto API, so the generated value does not need to be submitted to a remote calculation endpoint.

How to Use the Password Generator

Choose a length, select the character groups you want to allow, optionally remove ambiguous or bracket characters, and select Generate password. Use the copy button to move the generated password into a password manager or account form.

How Password Entropy Is Estimated

For independent random choices from a pool of N possible characters and a password length of L, the idealized entropy is:

H = L × log₂(N)

If repeated characters are disabled, this page uses the logarithm of the number of possible ordered selections without replacement instead.

Password Length and Security Guidance

NIST’s current public guidance emphasizes length over forced composition rules. For passwords used as a single factor, NIST SP 800-63B requires verifiers to require at least 15 characters and recommends allowing long passwords. A generated password can still be compromised by reuse, phishing, malware, insecure storage, or a breached service, so use unique passwords and enable MFA or passkeys where available.

Limitations

The entropy estimate is mathematical, not a guarantee of crack time. It assumes uniform random generation and does not model the target service’s hashing method, rate limits, attacker hardware, credential leaks, or password reuse.

Frequently Asked Questions

Does this generator send my password to a server?

No. The generator code on this page uses the browser’s cryptographic random-number interface and produces the password locally.

Is a longer password better than adding many rules?

For randomly generated passwords, additional length rapidly increases the search space. NIST guidance also prioritizes password length and does not recommend mandatory composition rules for user-chosen passwords.

What does password entropy mean?

Entropy is an idealized measure of how many equally likely possibilities the generator can produce. Higher bit values correspond to a larger search space, but real security depends on more than entropy alone.

Should I reuse a generated password?

No. Use a unique password for each account so that a compromise on one service does not automatically expose other accounts.
