What Is a Scientific Calculator for Your Site?

A scientific calculator extends basic arithmetic with trigonometric, logarithmic, exponential, root, factorial, and constant functions. This page packages those features in a self-contained HTML tool and supplies iframe code for embedding.

Degrees vs. Radians

Trigonometric functions depend on angle units. In Degree mode, the calculator converts the displayed angle to radians before calling the underlying trigonometric functions. Inverse trig converts the returned radian value back to degrees when Degree mode is active.

radians = degrees × π ÷ 180

Logs, Powers, and Roots

ln is the natural logarithm (base e), while log is base 10. The xʸ key starts exponentiation, x² squares the current expression value, √ computes the principal square root, and ∛ computes the real cube root.

Numerical Limits

Browser calculations use IEEE-754 double-precision floating-point numbers. Extremely large or tiny values can overflow, underflow, or accumulate rounding error. Factorial is limited to 170! because larger factorials exceed the finite range of a JavaScript Number.

Frequently Asked Questions

Does sin(30) equal 0.5?

Yes in Degree mode. In Radian mode, sin(30) treats 30 as radians and produces a different result.

What is the difference between ln and log?

ln is logarithm base e. The log key on this page is logarithm base 10.

Can the calculator compute factorials?

Yes for non-negative integers from 0 through 170.

Can I embed this scientific calculator?
