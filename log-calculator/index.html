Use the Log Calculator to calculate the logarithm of a positive number in any valid real base. Enter the number x and base b to find logᵦ(x) and compare the result with natural log, common log, and exponential verification.

What Is the Log Calculator?

The Log Calculator finds the exponent to which a base must be raised to produce a given number.

For example:

log₂(8) = 3

because:

2³ = 8

The calculator is useful when working with logarithmic equations, exponential functions, algebra, scientific calculations, growth and decay models, or any problem that requires a logarithm with a base other than 10 or e.

For real logarithms, the number must be greater than zero, and the base must be positive and cannot equal 1.

How to Use the Log Calculator

Enter the following values:

Number x

Enter the positive number whose logarithm you want to calculate.

Required condition:

x > 0

For example, you can enter 64.

Base b

Enter the logarithm base.

The base must satisfy:

b > 0

and:

b ≠ 1

Examples of valid bases include 2, 10, e, and other positive values except 1.

After entering both values, the calculator determines the logarithm and its supporting values.

Formula / Calculation Method

Main Formula

The calculator uses the change-of-base formula:

logᵦ(x) = ln(x) / ln(b)

A logarithm is also equivalent to the exponential relationship:

logᵦ(x) = y ⇔ bʸ = x

The change-of-base formula allows a logarithm with almost any valid real base to be calculated using natural logarithms.

Variables

Symbol Meaning Unit
x Number whose logarithm is calculated None
b Logarithm base None
y Calculated logarithm None
ln(x) Natural logarithm of x None
ln(b) Natural logarithm of the base None

Calculation Sequence

The calculation follows these steps:

  1. Check that x > 0.
  2. Check that b > 0 and b ≠ 1.
  3. Calculate ln(x).
  4. Calculate ln(b).
  5. Divide ln(x) by ln(b).
  6. Return the logarithm result.
  7. Verify the result using bʸ = x.

Natural Log

The natural logarithm uses base e, where:

e ≈ 2.71828

It is written as:

ln(x)

For example:

ln(64) ≈ 4.158883

Common Log

The common logarithm uses base 10.

It is normally written as:

log(x)

or

log₁₀(x)

For example:

log₁₀(1000) = 3

because:

10³ = 1000

OpenStax defines the common logarithm as base 10 and the natural logarithm as base e.

Exponential Verification

The calculated logarithm can be checked by raising the base to the calculated result:

bʸ = x

If:

log₂(64) = 6

then:

2⁶ = 64

This confirms the logarithm result.

Worked Example

Calculate:

log₂(64)

Inputs

  • Number x = 64
  • Base b = 2

Step 1: Apply the Formula

log₂(64) = ln(64) / ln(2)

Step 2: Calculate the Natural Logs

ln(64) ≈ 4.1588830834
ln(2) ≈ 0.6931471806

Step 3: Divide

log₂(64) = 4.1588830834 / 0.6931471806
log₂(64) = 6

Final Result

log₂(64) = 6

Verification:

2⁶ = 64

The supporting logarithms are approximately:

  • Natural log: ln(64) ≈ 4.158883
  • Common log: log₁₀(64) ≈ 1.806180

Understanding Your Results

Logarithm Result

The main result tells you the exponent required to raise the selected base to the entered number.

For example:

log₅(125) = 3

means:

5³ = 125

Natural Log

The natural log shows the logarithm of the entered number using base e.

It is commonly written as:

ln(x)

Common Log

The common log shows the logarithm using base 10:

log₁₀(x)

Exponential Check

The exponential check confirms the result by evaluating:

b^(logᵦ(x))

The result should return the original value of x, apart from possible decimal rounding for results that cannot be represented exactly.

Assumptions and Limitations

This calculator evaluates real logarithms only. It does not calculate complex logarithms.

Valid inputs must satisfy:

x > 0
b > 0
b ≠ 1

A real logarithm is not defined for zero or negative x.

Base 1 is invalid because 1 raised to any real exponent remains 1, so it cannot provide a unique logarithmic relationship.

Many logarithms are irrational numbers, so their displayed decimal values may be rounded.

Frequently Asked Questions

What does a logarithm calculate?

A logarithm finds the exponent required to raise a base to a specific number. For example, log₂(8) = 3 because 2³ = 8.

What formula does the Log Calculator use?

It uses the change-of-base formula:

logᵦ(x) = ln(x) / ln(b)

This allows logarithms with different valid bases to be calculated using natural logarithms.

Can the logarithm base be any number?

The base can be any positive real number except 1. Therefore, it must satisfy b > 0 and b ≠ 1.

Can I calculate the log of a negative number?

Not with this calculator. A negative number does not have a real logarithm, so the calculator is limited to x > 0.

What is the difference between log and ln?

ln(x) is the natural logarithm with base e. The common logarithm normally uses base 10 and is written as log(x) or log₁₀(x).

Why is base 1 not allowed?

Every real power of 1 equals 1. Because of this, base 1 does not create the one-to-one exponential relationship needed to define a logarithm.

How can I check whether a logarithm answer is correct?

Raise the base to the calculated logarithm:

bʸ = x

For example, if log₂(32) = 5, then 2⁵ = 32, confirming the result.
