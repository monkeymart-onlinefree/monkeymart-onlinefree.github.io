Use the Percent Error Calculator to compare an observed or experimental value with an accepted or reference value. It calculates percent error and supporting values including absolute error, relative error, and signed error.

What Is the Percent Error Calculator?

The Percent Error Calculator measures how far an observed value differs from an accepted value relative to the size of that accepted value.

It is useful when comparing an experimental measurement, estimate, calculated result, or approximation with a known reference value. Percent error expresses the size of the difference as a percentage, while the supporting error values show the difference in other forms.

How to Use the Percent Error Calculator

Enter the two values used for the comparison:

  1. Observed / Experimental Value: Enter the value you measured, calculated, estimated, or observed.
  2. Accepted / Reference Value: Enter the value being used as the reference for the comparison.

Both values should represent the same quantity and use compatible units.

The calculator then determines the signed error, absolute error, relative error, and percent error.

Formula / Calculation Method

Main Formula

The percent error formula is:

Percent Error = |Observed − Accepted| ÷ |Accepted| × 100%

Equivalently:

Percent Error = Relative Error × 100%

NIST defines absolute error as the magnitude of the difference between an approximation and its reference value, and relative error as absolute error divided by the magnitude of the reference value.

Variables

  • Observed (O): The experimental, measured, calculated, or estimated value.
  • Accepted (A): The reference value used for comparison.
  • | |: Absolute value, which makes the enclosed result non-negative.
  • Percent Error: Relative error expressed as a percentage.

The observed and accepted values should use the same unit. Signed and absolute error retain that unit, while relative error is dimensionless and percent error is expressed as a percentage.

Calculation Sequence

The calculator uses the two entered values in the following sequence:

  1. Find the signed difference between the observed and accepted values.
  2. Take the absolute value of that difference to determine absolute error.
  3. Divide the absolute error by the absolute value of the accepted value.
  4. Multiply the relative error by 100 to express it as percent error.

Signed Error

The signed error is:

Signed Error = Observed − Accepted

A positive result means the observed value is above the accepted value. A negative result means it is below the accepted value.

NIST measurement terminology defines error as a measurement result minus the value of the measurand, supporting this signed-difference convention when a reference value is used for comparison.

Absolute Error

Absolute error removes the sign from the difference:

Absolute Error = |Observed − Accepted|

NIST's DLMF gives the corresponding absolute-error definition as the magnitude of the difference between an approximation and the reference value.

Relative Error

Relative error compares the absolute error with the magnitude of the accepted value:

Relative Error = |Observed − Accepted| ÷ |Accepted|

Relative error has no unit because the units in the numerator and denominator cancel. The accepted value must be nonzero for relative error to be defined.

Percent Error

Percent error converts relative error to percentage form:

Percent Error = Relative Error × 100%

This shows the error relative to the accepted value on a percentage scale.

Worked Example

Suppose the observed value is 47.5 and the accepted value is 50.

Inputs

  • Observed value = 47.5
  • Accepted value = 50

Step 1: Calculate Signed Error

Signed Error = 47.5 − 50
Signed Error = −2.5

Step 2: Calculate Absolute Error

Absolute Error = |−2.5|
Absolute Error = 2.5

Step 3: Calculate Relative Error

Relative Error = 2.5 ÷ |50|
Relative Error = 0.05

Step 4: Calculate Percent Error

Percent Error = 0.05 × 100%

Final Result

Percent Error = 5%

The observed value is therefore 5% away from the accepted value. Because the signed error is negative, the observed value is lower than the accepted value.

Understanding Your Results

Percent Error

Percent error shows the size of the difference relative to the accepted value. A result of 5%, for example, means the absolute difference is equal to 5% of the magnitude of the accepted value.

Percent error uses an absolute difference, so its result is non-negative.

Absolute Error

Absolute error shows the size of the difference in the same unit as the original values.

If two lengths differ by 2 cm, for example, the absolute error is 2 cm.

Relative Error

Relative error expresses the error as a proportion of the accepted value rather than as a percentage.

For example:

Relative error = 0.05

is equivalent to:

Percent error = 5%

Signed Error

Signed error preserves the direction of the difference.

  • Positive signed error: observed value is greater than the accepted value.
  • Negative signed error: observed value is less than the accepted value.
  • Zero signed error: both values are equal.

Assumptions and Limitations

The observed and accepted values should describe the same quantity and use compatible units.

The accepted value cannot be zero when calculating relative error or percent error, because the formula requires division by the magnitude of the accepted value. NIST similarly defines relative error only when the reference value is nonzero.

If the observed value equals the accepted value, the signed error, absolute error, relative error, and percent error are all zero.

Percent error measures disagreement with a reference value. It does not by itself measure measurement uncertainty, repeatability, precision, or statistical significance. NIST distinguishes measurement error from measurement uncertainty and notes that measurement error may be unknown even when uncertainty can be evaluated.

When checking calculations manually, keep sufficient decimal precision until the final step to avoid differences caused by early rounding.

Frequently Asked Questions

What is the formula for percent error?

The formula is:

Percent Error = |Observed − Accepted| ÷ |Accepted| × 100%

First calculate the absolute difference, divide it by the magnitude of the accepted value, and then multiply by 100.

Can percent error be negative?

Not with this formula. The absolute difference and absolute accepted value are used, so percent error is non-negative.

The separate signed error can be positive or negative.

What does a percent error of 0% mean?

A percent error of 0% means the observed value and accepted value are equal.

What happens if the accepted value is zero?

Percent error and relative error are undefined because their formulas require division by the absolute value of the accepted value. Division by zero is not defined.

Signed error and absolute difference can still be determined independently.

What is the difference between absolute error and percent error?

Absolute error gives the size of the difference in the original unit:

Absolute Error = |Observed − Accepted|

Percent error compares that difference with the accepted value:

Percent Error = Absolute Error ÷ |Accepted| × 100%
What is the difference between relative error and percent error?

Relative error is expressed as a decimal or ratio. Percent error is the same relative error multiplied by 100 and expressed as a percentage.

For example, a relative error of 0.08 equals a percent error of 8%.

Is percent error the same as measurement uncertainty?

No. Percent error compares an observed value with a reference value. Measurement uncertainty describes uncertainty associated with a measurement result and is a separate metrology concept.
