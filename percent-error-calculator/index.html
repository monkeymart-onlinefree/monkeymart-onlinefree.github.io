What Is a Percent Error Calculator?

A percent error calculator measures how far an observed or experimental value is from an accepted reference value relative to that reference. It is useful in laboratory work, calibration checks, engineering comparisons, and classroom calculations where the magnitude of the error matters.

How to Use the Percent Error Calculator

  1. Enter the observed or experimental value.
  2. Enter the accepted or reference value.
  3. Select Calculate Error. The result panel shows the percent error plus supporting error measures.

Percent Error Formula

Percent error = |observed − accepted| / |accepted| × 100%

NIST defines absolute error as the magnitude of the difference between an approximation and the reference quantity, and relative error as absolute error divided by the magnitude of the reference value. Percent error is that relative error expressed as a percentage.

Calculation Example

If the observed value is 95 and the accepted value is 100, the absolute error is 5. Dividing 5 by 100 gives 0.05, so the percent error is 5%.

Limitations

Percent error is undefined when the accepted value is zero. It also describes disagreement with a reference value, not measurement uncertainty, repeatability, or statistical significance. For metrology work, error and uncertainty should not be treated as identical concepts.

Frequently Asked Questions

What is the difference between absolute and percent error?

Absolute error is expressed in the same units as the measured quantity. Percent error scales that difference by the accepted value, which makes comparisons across different magnitudes easier.

Should the denominator use the observed or accepted value?

For the standard percent-error calculation used here, the denominator is the absolute accepted or reference value. Other fields may use different relative-difference conventions, so always match the formula to the context.
