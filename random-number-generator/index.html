What Is a Random Number Generator?

Answer: A random number generator selects values within a defined range. This page can produce integers or rounded decimals and uses the browser Web Crypto API when available.

How to Use the Random Number Generator

  1. Set lower and upper limits.
  2. Choose the number of results and integer or decimal output.
  3. Optionally prevent duplicates and sort the output.
  4. Generate a new set whenever needed.

Generation Method

For a uniform interval, a random value U between 0 and 1 is scaled into the requested range. Integer generation maps U to one of the inclusive integer outcomes.

Calculation Example

With limits 1 and 100, integer mode can generate any whole number from 1 through 100 with equal-sized mapping intervals.

Assumptions and Limitations

Browser randomness is useful for general-purpose selection. Do not rely on this page alone for regulated lotteries, audited drawings, cryptographic key generation, or safety-critical applications.

Random Number Generator FAQs

Are the limits included for integers?

Yes. Integer mode includes both the lower and upper integer limits.

Can I prevent duplicates?

Yes, provided the requested count does not exceed the available distinct outcomes after rounding.

Is this suitable for passwords or cryptographic keys?

No. Use a purpose-built cryptographic generator with the appropriate security design.
