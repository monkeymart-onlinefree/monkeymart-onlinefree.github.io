The Random Number Generator creates one or multiple random integers or decimal values between limits you choose. Enter the lower and upper limits, select how many numbers you need, choose the result type, and optionally control decimal precision, sorting, and duplicate results.

What Is a Random Number Generator?

A random number generator produces values from a defined numerical range without requiring you to select the numbers manually.

This calculator can generate integers or decimals and can return a single value or multiple values. It is useful for general-purpose tasks such as randomized selections, test data, games, simulations, classroom exercises, and choosing numbers within a custom range.

When supported by the browser, the calculator uses browser cryptographic randomness as its randomness source. MDN describes Crypto.getRandomValues() as providing cryptographically strong random values.

How to Use the Random Number Generator

Enter the settings that match the numbers you want to generate:

  1. Lower limit — Enter the lowest value for the requested range.
  2. Upper limit — Enter the highest value for the requested range.
  3. How many? — Choose the number of results to generate.
  4. Type — Select whether the results should be integers or decimals.
  5. Decimal places — For decimal results, choose the number of decimal places to display.
  6. Sort — Choose the available sorting option if you want the generated values ordered rather than left in their generated order.
  7. No duplicate results — Enable this option when every returned result should be unique.

The calculator then displays the generated values according to these settings.

Formula / Calculation Method

Main Formula

The calculator starts with a random value:

0≤U<10 \le U < 1

where UU is a random value distributed across the interval from 0 up to, but not including, 1.

A random value in a custom decimal range can be represented as:

x=L+U(H−L)x = L + U(H-L)

where:

  • xx = generated value
  • LL = lower limit
  • HH = upper limit
  • UU = random value from 0 to less than 1

This scales the random value from its original 0-to-1 interval into the range selected by the user. Scaling a 0-to-less-than-1 random value into another numerical range is a standard random-number technique.

Integer Formula

For integer limits where both endpoints are included, the mapping is:

x=⌊U(H−L+1)⌋+Lx=\lfloor U(H-L+1)\rfloor+L

The +1+1 accounts for the upper integer so that every integer from LL through HH can be selected.

For example, a range from 1 through 10 contains 10 possible integer outcomes:

1,2,3,4,5,6,7,8,9,101,2,3,4,5,6,7,8,9,10

MDN documents the same general floor-based method for mapping a random value to inclusive integer limits.

Variables

Symbol Meaning Unit
UU Random value used for scaling None
LL Lower limit Same numerical unit as the input
HH Upper limit Same numerical unit as the input
xx Generated result Same numerical unit as the limits

Calculation Sequence

The calculator follows this general process:

  1. Read the lower and upper limits.
  2. Generate a random value UU.
  3. Scale UU into the selected numerical range.
  4. Apply integer mapping when Integer is selected.
  5. Apply the selected decimal precision when Decimal is selected.
  6. Generate additional values when more than one result is requested.
  7. Apply the no-duplicate requirement when enabled.
  8. Apply the selected sorting option.
  9. Display the final generated values.

Decimal Results

For decimal mode, the basic range transformation is:

x=L+U(H−L)x=L+U(H-L)

The Decimal places setting controls the precision shown in the final result.

For example, a generated value such as:

7.438291...7.438291...

may be displayed as:

7.447.44

when two decimal places are selected.

No Duplicate Results

When No duplicate results is enabled, the final set is required to contain unique values.

For integer generation, the number of unique values that can exist is limited by the size of the selected integer range.

For example, from 1 through 5 there are only five unique integers:

1,2,3,4,51,2,3,4,5

A request for more unique integers than the range contains cannot produce the requested number of distinct integer results.

Sorting

Sorting changes the order in which the generated results are displayed. It does not change the numerical range from which those results were generated.

Depending on the selected option, results can be ordered or left in their generated order.

Worked Example

Suppose you want three unique random integers from 1 through 10 and want the final values sorted.

Inputs

  • Lower limit: 1
  • Upper limit: 10
  • How many?: 3
  • Type: Integer
  • Sort: Ascending
  • No duplicate results: Enabled

Because random results change from one generation to another, the following UU values are illustrative values used only to demonstrate the calculation.

Assume:

U1=0.18U_1=0.18 U2=0.73U_2=0.73 U3=0.42U_3=0.42

Step 1

For the first result:

x=⌊0.18(10−1+1)⌋+1x=\lfloor0.18(10-1+1)\rfloor+1 x=⌊1.8⌋+1x=\lfloor1.8\rfloor+1 x=2x=2

Step 2

For the second result:

x=⌊0.73(10)⌋+1x=\lfloor0.73(10)\rfloor+1 x=⌊7.3⌋+1x=\lfloor7.3\rfloor+1 x=8x=8

Step 3

For the third result:

x=⌊0.42(10)⌋+1x=\lfloor0.42(10)\rfloor+1 x=⌊4.2⌋+1x=\lfloor4.2\rfloor+1 x=5x=5

The generated values are therefore:

2, 8, 52,\ 8,\ 5

After ascending sorting:

2, 5, 82,\ 5,\ 8

Final Result

2, 5, 8

A new generation can produce different values because the random input values change.

Understanding Your Results

The main output is the set of generated values.

An integer result contains whole numbers from the requested integer range. A decimal result contains values from the selected numerical interval and is displayed using the chosen decimal precision.

If multiple results are requested, the calculator returns the requested collection subject to the selected settings. Enabling no duplicates means the returned values must be distinct, while sorting controls their displayed order.

Random generation does not mean every small batch will contain evenly spaced numbers. Uniform random selection means outcomes have the intended opportunity to occur over repeated generation; short sequences can still contain clusters or apparent patterns.

Assumptions and Limitations

The calculator is designed for general-purpose random number generation.

Browser-based randomness is appropriate for many ordinary tasks, but this page should not by itself be treated as an audited drawing system for regulated lotteries or other formally controlled selections.

It should also not be used as a complete cryptographic key-generation system. MDN specifically recommends dedicated Web Crypto key-generation methods when cryptographic keys are required rather than manually using random values as a substitute for proper key-generation procedures.

When unique integers are required, the selected range must contain enough possible integer values to satisfy the requested quantity.

Decimal precision affects how the result is displayed. It should not be interpreted as measurement accuracy.

Because the generator is random, repeating the same inputs does not normally produce the same set of results.

Frequently Asked Questions

Is the upper limit included for integer results?

Yes. Integer generation maps the random value across the complete inclusive integer range, so both the lower and upper integer limits can be possible outcomes.

Can I generate more than one random number?

Yes. Use How many? to request multiple generated values instead of a single result.

Can the generator create decimal numbers?

Yes. Select the decimal result type and use Decimal places to control the precision shown in the output.

What does “No duplicate results” mean?

It means each value in the final generated set must be unique. For integers, the selected range must contain at least as many possible integers as the number of unique results requested.

Does sorting make the numbers less random?

Sorting only changes the displayed order after generation. It does not change the selected lower or upper limits.

Why do I get different answers with the same inputs?

The inputs define the range and generation settings rather than one fixed mathematical answer. New random values are generated each time, so different runs can produce different results.

Can I use this generator for passwords or cryptographic keys?

The calculator should not be treated as a replacement for a dedicated password generator, cryptographic key-generation API, or audited security system. Web Crypto provides specialized methods for security-sensitive cryptographic operations.
