# CalcPro reference review — 24 September 2026

Scope: every one of the 212 spreadsheet-mapped pages is listed below. Reference pages were retrieved from Calculator.net; input/heading text was screened against the current local controls. This is a feature-inventory comparison, not a certification of numerical parity or a live performance benchmark.

“Review candidates” are terminology-based differences, not proven missing functionality. Different labels, hidden modes and source extraction can produce false positives. A blank candidate list does not prove feature parity. Detailed upgrades were implemented and mathematically checked for amortization, loan schedules and interest projections. Other calculator formulas were preserved.

Shared changes: linked category/subcategory navigation, searchable category directories, consistent search taxonomy, print controls, and CSV exports on result tables with a generated tbody. Existing articles and routes were preserved.

Limitations: Chromium was unavailable and downloads failed. Desktop/mobile visual behavior, browser runtime correctness across all tools, real-user performance and comparative Calculator.net timing are NOT verified. Tax/medical datasets were not revalidated by this structural update.
