Use the Ratio Calculator to solve a proportion in the form A:B = C:D when one of the four values is unknown. Enter any three values and leave one field blank to calculate the missing term. The calculator can also help express equivalent two-number ratios in a simpler form.

What Is the Ratio Calculator?

A ratio compares two quantities, while a proportion states that two ratios are equal. A proportion can be written as:

A:B = C:D

or:

A / B = C / D

The Ratio Calculator finds the missing value that makes both ratios equivalent. It is useful for scaling quantities, recipes, measurements, maps, rates, and other situations where two ratios should remain proportional.

OpenStax defines a proportion as an equation in which two ratios or rates are equal.

How to Use the Ratio Calculator

The calculator uses four fields arranged as:

A : B = C : D

Enter values in any three fields and leave the value you want to calculate blank.

A — the first term of the first ratio.

B — the second term of the first ratio. Because it acts as a denominator in A/B, it cannot be zero.

C — the first term of the second ratio.

D — the second term of the second ratio. Because it acts as a denominator in C/D, it cannot be zero.

For example, to solve:

3 : 5 = 12 : ?

enter:

  • A = 3
  • B = 5
  • C = 12
  • D = blank

The calculator then finds the value of D that makes the two ratios equal.

When ratios represent measured quantities, keep corresponding terms consistent. For example, if A represents miles and B represents hours, C and D should follow the same miles-to-hours order.

Formula / Calculation Method

Main Formula

The calculator is based on the proportion:

A / B = C / D

where:

B ≠ 0 and D ≠ 0

A true proportion has equal cross products:

A × D = B × C

This cross-product relationship is the main calculation used to solve for a missing term.

Variables

Variable Meaning Unit
A First term of the first ratio Same unit type as C, when units apply
B Second term of the first ratio Same unit type as D, when units apply
C First term of the second ratio Same unit type as A, when units apply
D Second term of the second ratio Same unit type as B, when units apply

Ratios may also be unitless when they simply compare numbers.

Solving for A

Starting with:

A × D = B × C

divide both sides by D:

A = (B × C) / D

Solving for B

Starting with:

A × D = B × C

divide both sides by C:

B = (A × D) / C

Solving for C

Starting with:

A × D = B × C

divide both sides by B:

C = (A × D) / B

Solving for D

Starting with:

A × D = B × C

divide both sides by A:

D = (B × C) / A

These rearrangements follow directly from the cross-product equation. Values used as divisors must be nonzero.

Calculation Sequence

  1. Read the three entered values and identify the blank term.
  2. Represent the ratios as A/B = C/D.
  3. Set the cross products equal: A × D = B × C.
  4. Rearrange the equation for the missing variable.
  5. Calculate the unknown value.
  6. Use the completed values to represent the equivalent ratios.

Simplifying a Ratio

A ratio can also be written as a fraction. For whole-number ratios, an equivalent simpler ratio can be produced by dividing both terms by a common factor. Dividing by the greatest common factor reduces the ratio as far as possible while preserving the same relationship.

For example:

12 : 20

The greatest common factor of 12 and 20 is 4.

12 ÷ 4 : 20 ÷ 4 = 3 : 5

Therefore:

12 : 20 = 3 : 5

Worked Example

Suppose you want to find the missing value in:

3 : 5 = 12 : D

Inputs

  • A = 3
  • B = 5
  • C = 12
  • D = unknown

Step 1

Write the proportion:

3 / 5 = 12 / D

Step 2

Cross multiply:

3 × D = 5 × 12
3D = 60

Step 3

Divide both sides by 3:

D = 60 / 3
D = 20

Final Result

D = 20

The completed proportion is:

3 : 5 = 12 : 20

Check the cross products:

3 × 20 = 60
5 × 12 = 60

Because both cross products are equal, the proportion is valid.

The second ratio also simplifies:

12 : 20 = 3 : 5

Understanding Your Results

Missing Value

The main result is the number required to make the two ratios equal.

For example:

4 : 7 = 20 : 35

Both ratios describe the same proportion because:

4 / 7 = 20 / 35

and their cross products are equal.

Completed Proportion

After the missing term is calculated, the four values form a complete proportion:

A : B = C : D

The result means the relationship between A and B is equal to the relationship between C and D.

Simplified Ratio

When a ratio is reduced, the values become smaller while maintaining the same proportional relationship.

For example:

18 : 24 = 3 : 4

The numbers change, but the ratio remains equivalent.

Assumptions and Limitations

The Ratio Calculator solves one four-term proportion at a time. Enter three known terms and leave only one term unknown.

The denominator positions B and D cannot be zero, because division by zero is undefined. OpenStax likewise defines a proportion A/B = C/D with nonzero denominators.

Some zero-value combinations can also produce undefined or non-unique solutions when solving for a term requires division by zero.

The calculator does not determine whether the quantities you enter are logically compatible. When units are involved, corresponding terms should represent compatible quantities and should remain in the same order.

Cross multiplication applies when two ratios are set equal as a proportion. It should not automatically be applied to unrelated equations that do not have this structure.

The mathematical result is meaningful for real-world scaling only when the quantities actually have a proportional relationship.

If a result is displayed as a rounded decimal, the exact mathematical value may contain additional digits.

Frequently Asked Questions

What formula does the Ratio Calculator use?

It uses:

A / B = C / D

and the cross-product relationship:

A × D = B × C

The equation is rearranged depending on which of the four values is missing.

Can I leave two values blank?

The calculator is designed to solve one unknown in a four-term proportion. With more than one unknown, there is usually not enough information to determine one unique solution.

Why can't B or D equal zero?

B and D are denominator terms in A/B = C/D. Division by zero is undefined, so a valid proportion requires both denominator terms to be nonzero.

How do you simplify a ratio?

For a whole-number ratio, divide both terms by a common factor. Dividing by their greatest common factor gives a fully reduced equivalent ratio.

For example:

16 : 24

Divide both numbers by 8:

2 : 3
Do units matter in a proportion?

Yes, when the numbers represent measurements. Corresponding terms should use compatible quantities and remain in the same order. For example, if the first ratio is distance to time, the second ratio should also be distance to time.

Is cross multiplication always valid?

Cross multiplication is appropriate when two ratios are set equal as a proportion. It should not be treated as a general rule for every equation containing fractions.

How can I check the calculated answer?

Substitute the result back into the original proportion and compare the cross products.

If:

A × D = B × C

the completed ratios are equivalent.
