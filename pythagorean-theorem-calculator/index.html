Use the Pythagorean Theorem Calculator to find a missing side of a right triangle. Enter two known side lengths to calculate the hypotenuse c or the missing leg b using the Pythagorean theorem.

What Is the Pythagorean Theorem Calculator?

The Pythagorean Theorem Calculator finds an unknown side length in a right triangle from two known sides.

You can use it to:

  • Find the hypotenuse c when legs a and b are known.
  • Find leg b when leg a and hypotenuse c are known.

It is useful for geometry problems and other situations involving right-triangle measurements.

How to Use the Pythagorean Theorem Calculator

Choose the value you want to find and enter the required known side lengths.

Find Hypotenuse c

Enter:

  • Side a: Length of the first leg.
  • Side b: Length of the second leg.

The calculator uses these two values to calculate hypotenuse c.

Find Leg b

Enter:

  • Side a: Length of the known leg.
  • Side c: Length of the hypotenuse.

The calculator calculates the missing leg b.

Use the same measurement unit for all side lengths. For example, if side a is entered in centimeters, the other side and calculated result will also represent centimeters.

Formula / Calculation Method

Main Formula

The calculator uses the Pythagorean theorem:

a² + b² = c²

This relationship applies to a right triangle, where a and b are the legs and c is the hypotenuse. The hypotenuse is the side opposite the 90° angle.

Variables

Symbol Meaning Unit
a First leg of the right triangle Any consistent length unit
b Second leg of the right triangle Same length unit as a and c
c Hypotenuse, opposite the 90° angle Same length unit as a and b

Finding the Hypotenuse c

When a and b are known:

c = √(a² + b²)

Calculation sequence:

  1. Square side a.
  2. Square side b.
  3. Add the two squared values.
  4. Take the positive square root of the sum.
  5. The result is hypotenuse c.

Finding Leg b

When a and hypotenuse c are known, rearrange the same theorem:

b = √(c² − a²)

Calculation sequence:

  1. Square hypotenuse c.
  2. Square side a.
  3. Subtract a² from c².
  4. Take the positive square root.
  5. The result is leg b.

Because c is the hypotenuse, it must be longer than either individual leg of a valid right triangle.

Worked Example

Suppose a right triangle has:

Inputs

  • Side a = 3
  • Side b = 4
  • Find hypotenuse c

Step 1

Apply the formula:

c = √(a² + b²)

Substitute the known values:

c = √(3² + 4²)

Step 2

Square both legs:

c = √(9 + 16)

Step 3

Add the squared values:

c = √25

Final Result

c = 5

A right triangle with legs of 3 and 4 therefore has a hypotenuse of 5.

Understanding Your Results

The main result is the missing side length.

If you select Find Hypotenuse c, the result represents the side opposite the right angle.

If you select Leg b, the result represents the missing leg calculated from the known leg a and hypotenuse c.

The result uses the same length unit as the values entered. If the square root is not a whole number, the calculated side may be a decimal.

Assumptions and Limitations

This calculator is designed specifically for right triangles. The Pythagorean theorem does not directly calculate side lengths for triangles that do not contain a 90° angle.

Side lengths should be positive numbers and should use the same measurement unit.

When calculating leg b, the hypotenuse c must be longer than side a. A value where c ≤ a cannot produce a positive missing leg for a valid right triangle using this calculation.

The calculator performs numerical calculations rather than symbolic mathematical proofs.

Some decimal calculations can contain very small floating-point representation differences. Displayed results may therefore be rounded when necessary.

Frequently Asked Questions

What does the Pythagorean Theorem Calculator calculate?

It calculates a missing side of a right triangle. The tool can find hypotenuse c from legs a and b, or find leg b from side a and hypotenuse c.

What is the Pythagorean theorem formula?

The formula is:

a² + b² = c²

Here, a and b are the two legs and c is the hypotenuse.

How do I find the hypotenuse?

Square both known legs, add the results, and take the positive square root:

c = √(a² + b²)
How do I find leg b when the hypotenuse is known?

Subtract the square of leg a from the square of hypotenuse c, then take the positive square root:

b = √(c² − a²)
Which side is the hypotenuse?

The hypotenuse is the side opposite the 90° angle. It is also the longest side of a right triangle.

Can I use centimeters, feet, meters, or inches?

Yes. The formula works with any length unit as long as both known sides use the same unit. The calculated side will use that unit as well.

Why might the result be a decimal?

Not every pair of side lengths produces a whole-number third side. Taking the square root can produce a non-integer result, so a decimal value may be required.
